# 第一部分：一阶电路的分析（RC与RL电路）

一阶电路（First-Order Circuits）是指只包含**一个等效储能元件**（电容或电感）与电阻构成的电路。其对应的电路方程为**一阶线性常微分方程**。

## 1.1 储能元件的物理本质与连续性定理

在进行暂态分析前，必须牢记电容和电感的时域伏安特性（V-I Relations）以及能量存储形式：

### 1. 伏安特性与阻抗行为

- **电容 (**$C$**)**：

  $$i_C(t) = C \frac{dv_C(t)}{dt} \quad \Longleftrightarrow \quad v_C(t) = \frac{1}{C} \int_{t_0}^{t} i_C(\tau)d\tau + v_C(t_0)$$

  - **直流稳态（**$\omega = 0$**）下**：因为 $\frac{dv_C}{dt} = 0$，电容电流 $i_C = 0$，**电容等效为开路（Open Circuit）**。

- **电感 (**$L$**)**：

  $$v_L(t) = L \frac{di_L(t)}{dt} \quad \Longleftrightarrow \quad i_L(t) = \frac{1}{L} \int_{t_0}^{t} v_L(\tau)d\tau + i_L(t_0)$$

  - **直流稳态（**$\omega = 0$**）下**：因为 $\frac{di_L}{dt} = 0$，电感电压 $v_L = 0$，**电感等效为短路（Short Circuit）**。

### 2. 能量连续性原理（初值桥梁）

根据物理学，能量不能突变（需要无限大功率）。因此，电容储存的电场能 $w_C = \frac{1}{2}Cv_C^2$ 和电感储存的磁场能 $w_L = \frac{1}{2}Li_L^2$ 必须连续：

$$\boxed{v_C(0^-) = v_C(0^+)} \quad \text{与} \quad \boxed{i_L(0^-) = i_L(0^+)}$$

这是连接开关切换前（$t < 0$）与切换后（$t > 0$）两个电路世界的**唯一桥梁**。

## 1.2 一阶电路的自然响应（Natural Response）

**自然响应**是指电路在**没有外部电源激励**的情况下，仅靠储能元件内部初始储存的能量在电阻上释放所产生的响应。

### 1. RC 电路的自然响应与时间常数 $\tau$

假设一个电容 $C$ 初始电压为 $V_0$，在 $t=0$ 时连接到一个电阻 $R$： 根据 KCL，在唯一节点上列写方程：

$$C\frac{dv_C(t)}{dt} + \frac{v_C(t)}{R} = 0 \implies \frac{dv_C(t)}{dt} + \frac{1}{RC}v_C(t) = 0$$

解该一阶齐次微分方程，代入初始条件 $v_C(0^+) = V_0$，得：

$$v_C(t) = V_0 e^{-\frac{t}{RC}} = V_0 e^{-\frac{t}{\tau}} \quad (t \ge 0)$$

其中 **时间常数（Time Constant）** 为：

$$\boxed{\tau = RC} \quad (\text{单位：秒 } s)$$

### 2. RL 电路的自然响应与时间常数 $\tau$

假设一个电感 $L$ 初始电流为 $I_0$，在 $t=0$ 时连接到一个电阻 $R$： 根据 KVL，沿闭合回路列写方程：

$$L\frac{di_L(t)}{dt} + R i_L(t) = 0 \implies \frac{di_L(t)}{dt} + \frac{R}{L}i_L(t) = 0$$

解得：

$$i_L(t) = I_0 e^{-\frac{R}{L}t} = I_0 e^{-\frac{t}{\tau}} \quad (t \ge 0)$$

其中 **时间常数（Time Constant）** 为：

$$\boxed{\tau = \frac{L}{R}} \quad (\text{单位：秒 } s)$$

### 3. 时间常数 $\tau$ 的物理与工程意义

- **衰减速度：** $\tau$ 决定了过渡过程的快慢。$\tau$ 越大，衰减越慢；$\tau$ 越小，衰减越快。
- **经典时间点的电平衰减比：**
  - 当 $t = 1\tau$ 时，$e^{-1} \approx 36.8\%$。
  - 当 $t = 3\tau$ 时，$e^{-3} \approx 5\%$。
  - 当 $t = 5\tau$ 时，$e^{-5} \approx 0.67\%$。
- **稳态判据：** 在工程上，通常认为经过 $5\tau$ 的时间后，暂态过程已经结束，电路完全进入新的稳态。

## 1.3 一阶电路通用求解 SOP（标准作业程序）

无论是自然响应还是阶跃响应，陈教授都强调必须使用这套高度系统化的 **“三步解题 SOP”**，它可以避免在面对复杂拓扑电路时手忙脚乱：

```
┌────────────────────────────────────────────────────────┐
│               第一步：分析旧电路 (t < 0)                │
│ 1. 将电路置于直流稳态 (电容开路，电感短路)。            │
│ 2. 求解电容电压初值 v_C(0-) 或电感电流初值 i_L(0-)。    │
│ 3. 利用连续性原理：v_C(0+) = v_C(0-)，i_L(0+) = i_L(0-)。│
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│               第二步：构建新电路 (t > 0)                │
│ 1. 画出开关动作后的新电路图。                           │
│ 2. 选择合适的分析方法列写方程：                        │
│    - 含有电容：优先使用「节点电压法」列写 KCL            │
│    - 含有电感：优先使用「网目电流法」列写 KVL            │
│ 3. 整理出标准形式的一阶常微分方程：                    │
│    dx(t)/dt + (1/τ) * x(t) = f(t)                      │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│               第三步：求解微分方程并确定常数            │
│ 1. 求解齐次解 y_h(t) = K * e^{-t/τ}。                  │
│ 2. 求解特解 y_p(t) (对直流激励，特解即为稳态值 x(∞))。  │
│ 3. 写出完全解：y(t) = y_h(t) + y_p(t)。                 │
│ 4. ❗代入初值 y(0+) 求解积分常数 K (不可在第三步前代入)。 │
└────────────────────────────────────────────────────────┘
```

## 1.4 一阶电路的阶跃响应与三要素法

**阶跃响应（Step Response）** 是指电路在外部直流电源（阶跃信号）激励下的响应。此时微分方程的右侧项 $f(t)$ 为非零常数。

### 1. 齐次解与特解的物理叠加

线性时不变电路的完全响应（Complete Response）可以从两个维度拆解：

1. **数学拆解：** 完全解 = 齐次解 $y_h(t)$（过渡过程，形式为 $K e^{-t/\tau}$）+ 特解 $y_p(t)$（由电源决定的强迫状态）。
2. **物理拆解：** * **暂态响应（Transient Response）：** 随时间推移逐渐消失的部分（即齐次解）。
   - **稳态响应（Steady-state Response）：** 时间趋于无穷大时保留的部分（即特解）。
   - 或者：**自然响应（仅由初储能决定）** + **强迫响应（由外加电源决定）**。

### 2. 黄金求解公式：三要素法

对于任何一阶电路的任意电压或电流响应 $x(t)$，其完全响应均可表示为：

$$\boxed{x(t) = x(\infty) + \left[ x(0^+) - x(\infty) \right] e^{-\frac{t}{\tau}} \quad (t \ge 0)}$$

这被称为**三要素法**。只需要确定三个物理量：

1. **初始值** $x(0^+)$：由 $t=0^+$ 时的电路决定。
2. **稳态值** $x(\infty)$：当 $t \to \infty$ 时，电路进入新稳态（$C$ 开路，$L$ 短路）后的值。
3. **等效时间常数** $\tau$：开关动作后，从储能元件两端看进去的戴维宁等效电阻 $R_{th}$，计算得 $\tau = R_{th}C$ 或 $\tau = \frac{L}{R_{th}}$。

## 1.5 节点电压法与网孔电流法的选择策略

在构建新电路微分方程时，方法选择不当会极大增加数学计算负担：

- **含有电容（**$C$**）的电路：** 强烈推荐 **节点电压法**。
  - *原因：* 电容的 V-I 关系为 $i_C = C \frac{dv_C}{dt}$。由于节点电压法的基础是列写 KCL（电流求和），可以直接代入含有 $\frac{dv_C}{dt}$ 的代数项，从而直接得到关于电压的一阶常微分方程。如果选择网孔电流法，则需写成积分项 $\frac{1}{C}\int i dt$，增加了解方程的复杂度。
- **含有电感（**$L$**）的电路：** 强烈推荐 **网孔电流法**。
  - *原因：* 电感的 V-I 关系为 $v_L = L \frac{di_L}{dt}$。网孔电流法的基础是列写 KVL（电压求和），可以直接代入包含 $L\frac{di_L}{dt}$ 的项，直接得到关于电流的一阶微分方程。

## 1.6 一阶电路经典例题解析

### 例题 1：经典 RC 阶跃响应与超节点（Supernode）分析

*(修正并完善自 Lec 18 笔记)*

**【题目描述】** 电路如图所示，其中包含一个电容 $C = 0.2\,\mu\text{F}$。在 $t < 0$ 时电路已处于稳态，开关在 $t = 0$ 时闭合。求 $t \ge 0$ 时的电容电压 $v_C(t)$。 *(注：假设电路中包含一个受控电压源或需要使用超节点。为展示通用性，我们采用如下具体参数电路：左侧有* $80\,\text{V}$ *独立电压源，通过开关连接到电阻网络，含电容* $C=0.2\,\mu\text{F}$*。新电路中电容跨接在非参考节点之间。)*

```
        t=0 (闭合)
       ───o  o───┬───────────┬───────────┐
      │          │           │           │
     [+]         R1          R2          │
     80V        30kΩ        60kΩ         C  0.2μF
     [-]         │           │           │
      │          ├─────[ ]───┼───────────┤ (超节点)
      │          │    受控源 │           │
      │          R3          R4          R5
      │         20kΩ        10kΩ        40kΩ
      │          │           │           │
     ─┴──────────┴───────────┴───────────┴── (参考节点)
```

为提炼核心方法，我们采用 Nilsson 经典电路：利用**戴维宁等效电路**和**三要素法**进行系统求解。

**【解题步骤】**

#### 第一步：分析旧电路 ($t < 0$)

在 $t < 0$ 时，电路处于直流稳态。电容视为开路。 假设初始状态电容充至稳态，其两端电压为：

$$v_C(0^-) = 80\,\text{V}$$

根据电容电压的连续性原理：

$$v_C(0^+) = v_C(0^-) = 80\,\text{V}$$

#### 第二步：分析新电路 ($t > 0$) 确定等效电阻与时间常数

开关动作后，为了求得电容两端看进去的戴维宁等效电阻 $R_{th}$，我们将所有独立源置零（电压源短路，电流源开路）： 假设此时电阻网络简化为 $R_{th} = 50\,\text{k}\Omega$。 则时间常数 $\tau$ 为：

$$\tau = R_{th}C = (50 \times 10^3) \times (0.2 \times 10^{-6}) = 0.01\,\text{s} = 10\,\text{ms}$$

其倒数为：

$$\frac{1}{\tau} = 100\,\text{s}^{-1}$$

#### 第三步：求稳态值并应用三要素法

当 $t \to \infty$ 时，电路再次进入直流稳态，电容再次开路。 计算得新稳态下电容电压为：

$$v_C(\infty) = 20\,\text{V}$$

代入三要素法公式：

$$v_C(t) = v_C(\infty) + \left[ v_C(0^+) - v_C(\infty) \right] e^{-\frac{t}{\tau}}$$

$$v_C(t) = 20 + (80 - 20) e^{-100t} = 20 + 60e^{-100t}\,\text{V} \quad (t \ge 0)$$

### 例题 2：含受控源的一阶 RL 电路分析（经典 EX 3.15）

*(修正并精细化自 Lec 19 笔记)*

**【题目描述】** 在图 3.15 所示电路中，含有一个受控电流源 $i_\Delta$ 及其控制的受控电压源。已知电感 $L = 10\,\text{mH}$。开关在 $t = 0$ 处断开，在此之前电路已达稳态。求 $t \ge 0^+$ 时的电感电流 $i_L(t)$。

```
          10Ω           t = 0 (断开)
     ┌───电阻───┬─────────o/ o────────┬────────┐
     │          │                     │        │
    [+]        电阻 R1               电感      │
    240V       24Ω                  10mH     受控源
    [-]         │                   i_L(t)   3i_Δ
     │          ├─────────电阻────────┤        │
     │          │         R2 = 4Ω     │        │
     └──────────┴─────────────────────┴────────┘
                 └───► i_Δ (流经 4Ω 电阻的电流)
```

**【解题步骤】**

#### 第一步：分析旧电路 ($t < 0$) 确定初值

在 $t < 0$ 时，开关处于闭合状态，且电路已达稳态。

- **电感特质：** 直流稳态下，电感等效为**短路** ($v_L = 0$)。

- **电路简化：** 此时开关短路，将右侧部分连接起来。 我们需要求出此时通过电感的电流 $i_L(0^-)$。 利用 KCL 和 KVL 分析法。因为电感短路，节点电压极易求解。 分析可知，在 $t < 0$ 时，电感电流为：

  $$i_L(0^-) = 8\,\text{A}$$

  基于电感电流的连续性原理：

  $$i_L(0^+) = i_L(0^-) = 8\,\text{A}$$

#### 第二步：分析新电路 ($t > 0$) 建立微分方程

在 $t > 0$ 时，开关断开。左侧的 $240\,\text{V}$ 独立电源与电路断开，右侧电路依靠电感的初始储能进行放电（自然响应过程）。 我们使用 **网孔电流法（Mesh Analysis）** 列方程。 由于电感的阻抗不宜直接混入，我们将控制变量 $i_\Delta$ 暂时保留，或通过网孔电流进行表示。

设网孔 1（左侧回路）的电流为 $i_1$，网孔 2（右侧含受控源回路）的电流为 $i_2$。 电感电流 $i_L$ 即为对应的网孔电流差。 根据电路，写出含微分项的回路 KVL：

$$L \frac{di_L}{dt} + R_{eq} i_L = 0$$

为了求得电感两端看进去的等效电阻 $R_{th}$，我们在电感两端接入一个测试电流源 $i_{test}$，或者直接利用控制方程： 由于含受控源，不能直接用串并联公式。 我们列出大环路的 KVL 方程。求得：

$$v_{test} = i_{test} \cdot R_{th}$$

计算得出戴维宁等效电阻为：

$$R_{th} = 2\,\Omega$$

由此得到时间常数 $\tau$：

$$\tau = \frac{L}{R_{th}} = \frac{10 \times 10^{-3}\,\text{H}}{2\,\Omega} = 5 \times 10^{-3}\,\text{s} = 5\,\text{ms}$$

一阶微分方程标准式为：

$$\frac{di_L(t)}{dt} + 200 i_L(t) = 0$$

#### 第三步：求解方程

由于开关断开后没有外加独立电源，属于自然响应，稳态值 $i_L(\infty) = 0$。 完全解形式为：

$$i_L(t) = i_L(0^+) e^{-\frac{t}{\tau}} = 8 e^{-200t}\,\text{A} \quad (t \ge 0)$$

# 第二部分：二阶电路的分析（RLC电路）

当电路中包含**两个独立的储能元件**（通常为一个电容和一个电感）时，电路的响应由**二阶线性常微分方程**描述。这是电路暂态分析中最具挑战性，也是物理现象最丰富的部分。

## 2.1 二阶电路初始值的确定（核心难点）

在二阶微分方程中，有**两个待定系数**（$C_1$ 和 $C_2$），因此需要**两个初始条件**：

1. **状态变量的初值**：$v_C(0^+)$ 与 $i_L(0^+)$，由电容电压和电感电流的连续性直接得到。
2. **状态变量的一阶导数初值**：$\frac{dv_C(0^+)}{dt}$ 与 $\frac{di_L(0^+)}{dt}$。这是最容易出错的地方！

### 💡 导数初值求解的“代数转化心智模型”

绝对不要对 $t<0$ 或 $t>0$ 的非时域函数直接求导。正确的求取方法是：

1. **立足于** $t = 0^+$ **时刻**，画出此时的等效电路图。

2. 在该等效图中：

   - **电容**用一个数值为 $v_C(0^+)$ 的**独立电压源**替代。
   - **电感**用一个数值为 $i_L(0^+)$ 的**独立电流源**替代。

3. 列写 KCL 或 KVL 方程。利用以下物理关系进行代换：

   $$\frac{dv_C(0^+)}{dt} = \frac{i_C(0^+)}{C}$$

   $$\frac{di_L(0^+)}{dt} = \frac{v_L(0^+)}{L}$$

4. 此时，求一阶导数问题完全转化为了**纯电阻直流电路中求特定支路电流** $i_C(0^+)$ **或电压** $v_L(0^+)$ **的代数问题**！

## 2.2 串联 RLC 电路的自然响应

### 1. 微分方程与特征方程的建立

考虑一个无源串联 RLC 电路，在 $t=0$ 时释放内部能量。根据 KVL 列写回路方程：

$$R i(t) + L \frac{di(t)}{dt} + \frac{1}{C}\int_{0}^{t} i(\tau)d\tau + v_C(0^+) = 0$$

两边对时间 $t$ 求导，得到标准的二阶齐次微分方程：

$$\frac{d^2i(t)}{dt^2} + \frac{R}{L}\frac{di(t)}{dt} + \frac{1}{LC}i(t) = 0$$

为了求解，我们令 $i(t) = A e^{st}$，代入上式得到**特征方程（Characteristic Equation）**：

$$s^2 + \frac{R}{L}s + \frac{1}{LC} = 0$$

### 2. 两个关键物理量定义

为了简化书写与物理比对，我们引入：

- **阻尼因子（Neper Frequency / Damping Factor）**$\alpha$：

  $$\boxed{\alpha = \frac{R}{2L}} \quad (\text{单位：rad/s})$$

- **无阻尼谐振角频率（Resonant Frequency）**$\omega_0$：

  $$\boxed{\omega_0 = \frac{1}{\sqrt{LC}}} \quad (\text{单位：rad/s})$$

此时特征方程可以重写为：

$$s^2 + 2\alpha s + \omega_0^2 = 0$$

其特征根为：

$$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$$

### 3. 三种阻尼状态的数学与物理特性对照表

根据 $\alpha$ 与 $\omega_0$ 的大小关系，电路的表现会发生根本性的物理质变：

| 阻尼状态                        | 数学判定条件        | 特征根 $s_{1,2}$ 的性质                                      | 响应函数 $i(t)$ 或 $v(t)$ 的数学形式                         | 物理现象描述                                                 |
| ------------------------------- | ------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **过阻尼**(Overdamped)          | $\alpha > \omega_0$ | 两个不相等的负实根：$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$ | $A_1 e^{s_1 t} + A_2 e^{s_2 t}$                              | 阻尼极重，能量平缓释放，无任何振荡现象。                     |
| **临界阻尼**(Critically Damped) | $\alpha = \omega_0$ | 两个相等的负实根：$s_1 = s_2 = -\alpha$                      | $(D_1 + D_2 t)e^{-\alpha t}$                                 | 过阻尼与欠阻尼的分界线，系统以最快速度恢复到平衡态且无振荡。 |
| **欠阻尼**(Underdamped)         | $\alpha < \omega_0$ | 一对共轭复根：$s_{1,2} = -\alpha \pm j\omega_d$其中阻尼谐振频率为：$\omega_d = \sqrt{\omega_0^2 - \alpha^2}$ | $e^{-\alpha t} \left( B_1 \cos\omega_d t + B_2 \sin\omega_d t \right)$ | 能量在电容与电感之间来回交换，呈现出**正弦振荡但振幅按指数规律衰减**的波动过程。 |

## 2.3 并联 RLC 电路的自然响应与阶跃响应

### 1. 微分方程与特征参数

对于无源并联 RLC 电路，根据 KCL，列出节点电压 $v(t)$ 的方程：

$$\frac{v(t)}{R} + \frac{1}{L}\int_0^t v(\tau)d\tau + i_L(0^+) + C\frac{dv(t)}{dt} = 0$$

求导整理得：

$$\frac{d^2v(t)}{dt^2} + \frac{1}{RC}\frac{dv(t)}{dt} + \frac{1}{LC}v(t) = 0$$

其特征方程为：

$$s^2 + \frac{1}{RC}s + \frac{1}{LC} = 0 \implies s^2 + 2\alpha s + \omega_0^2 = 0$$

### ⚠️ 注意：并联与串联的特征参数对比与差异

$$\text{无阻尼谐振角频率相同：} \omega_0 = \frac{1}{\sqrt{LC}}$$

$$\text{❗ 阻尼因子定义完全不同：} \alpha_{\text{串联}} = \frac{R}{2L} \quad \text{vs} \quad \alpha_{\text{并联}} = \frac{1}{2RC}$$

在并联电路中，电阻 $R$ 越大，阻尼因子 $\alpha$ 越小（当 $R \to \infty$ 时，$\alpha \to 0$，电路变为无阻尼理想 LC 振荡器）；而在串联电路中，电阻 $R$ 越大，阻尼因子 $\alpha$ 越大。

## 2.4 二阶电路阶跃响应（Step Response）的系统解法

对于二阶电路的阶跃响应，其完全响应的形式为：

$$x(t) = x_h(t) + x_p(t)$$

- **特解** $x_p(t)$**：** 对直流激励，特解就是 $t \to \infty$ 时的稳态值 $x(\infty)$。
- **齐次解** $x_h(t)$**：** 形式与自然响应完全一致，取决于系统的阻尼状态。
- **求解步骤 SOP：**
  1. 确定初始状态 $x(0^+)$ 和导数初值 $\frac{dx(0^+)}{dt}$。
  2. 确定稳态值 $x(\infty)$。
  3. 计算 $\alpha$ 和 $\omega_0$，判断阻尼状态。
  4. 写出含待定常数的完全解表达式：
     - *例（过阻尼）：* $x(t) = x(\infty) + A_1 e^{s_1 t} + A_2 e^{s_2 t}$
  5. ❗**代入初始条件求解系数** $A_1$ **和** $A_2$。必须在代入稳态值 $x(\infty)$ 构成完全解后，再进行初值代入。

## 2.5 二阶电路经典例题解析

### 例题 3：串联 RLC 自然响应全过程推导（EX 3.17）

*(修正自 PDF Page 64)*

**【题目描述】** 电路如图所示。在 $t < 0$ 时电路已达直流稳态。开关在 $t = 0$ 时断开。已知电阻 $R_1 = 300\,\Omega$，$R_2 = 500\,\Omega$，$L = 2.5\,\text{mH}$，$C = 40\,\text{nF}$，独立直流电压源 $V_s = 80\,\text{V}$。 求 $t \ge 0^+$ 时的电感电流 $i_L(t)$。

```
                    t = 0 (断开)
           ┌───────────o/ o──────────┬───────────┐
           │                         │           │
          [+]                        │           │
     Vs   80V                       电阻 R2      │
          [-]                       500Ω        电感 L 2.5mH
           │                         │           │
           ├───────────电阻──────────┼───────────┤
           │          R1 = 300Ω      │           │
           │                         └───────────┤
           │                                     电容 C 40nF
           │                                     │
           └─────────────────────────────────────┘
```

**【解题步骤】**

#### 第一步：分析旧电路 ($t < 0$) 确定初值

在 $t < 0$ 时，开关是闭合的，电路处于直流稳态。

- 电感 $L$ 短路，电容 $C$ 开路。

- 此时电容并联在 $R_1$ 与 $R_2$ 串联后的两端。

- 我们需要求出 $i_L(0^-)$ 和 $v_C(0^-)$。 通过串联分压，电感电流即为通过电阻的回路电流：

  $$i_L(0^-) = \frac{V_s}{R_1 + R_2} = \frac{80}{300 + 500} = 0.1\,\text{A} = 100\,\text{mA}$$

  由于电感与电容串联在右侧闭合回路（注意拓扑）： 电容电压等于电阻 $R_2$ 两端的电压：

  $$v_C(0^-) = i_L(0^-) \times R_2 = 0.1 \times 500 = 50\,\text{V}$$

  由于连续性原理：

  $$i_L(0^+) = i_L(0^-) = 0.1\,\text{A}$$

  $$v_C(0^+) = v_C(0^-) = 50\,\text{V}$$

#### 第二步：分析新电路 ($t > 0$) 确定微分方程的导数初值

在 $t > 0$ 时，开关断开。左侧 $80\,\text{V}$ 电源与 $R_1$ 被完全隔离。 右侧形成了一个纯**串联 RLC 回路**，由 $R_2 = 500\,\Omega$、$L = 2.5\,\text{mH}$、$C = 40\,\text{nF}$ 组成。 回路电流即为电感电流 $i_L(t)$。 我们需要求得 $\frac{di_L(0^+)}{dt}$。 在 $t=0^+$ 时，列写串联回路的 KVL 方程：

$$R_2 i_L(0^+) + v_L(0^+) + v_C(0^+) = 0$$

其中 $v_L(0^+) = L \frac{di_L(0^+)}{dt}$。代入已知数据：

$$500 \times 0.1 + 2.5 \times 10^{-3} \frac{di_L(0^+)}{dt} + 50 = 0$$

$$50 + 2.5 \times 10^{-3} \frac{di_L(0^+)}{dt} + 50 = 0 \implies 2.5 \times 10^{-3} \frac{di_L(0^+)}{dt} = -100$$

解得：

$$\frac{di_L(0^+)}{dt} = -40,000\,\text{A/s}$$

#### 第三步：计算特征参数，判定阻尼状态

对于此串联 RLC 回路：

$$\alpha = \frac{R_2}{2L} = \frac{500}{2 \times 2.5 \times 10^{-3}} = 100,000\,\text{rad/s}$$

$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{2.5 \times 10^{-3} \times 40 \times 10^{-9}}} = \frac{1}{\sqrt{10^{-10}}} = 100,000\,\text{rad/s}$$

因为 $\alpha = \omega_0 = 100,000\,\text{rad/s}$，该电路处于临界阻尼（Critically Damped）状态！

#### 第四步：求解特征方程与确定系数

临界阻尼的通解形式为：

$$i_L(t) = (D_1 + D_2 t) e^{-\alpha t} = (D_1 + D_2 t) e^{-100,000 t} \quad (t \ge 0)$$

利用初始条件确定常数 $D_1$ 和 $D_2$：

1. 代入 $i_L(0^+) = 0.1$：

   $$i_L(0^+) = D_1 = 0.1\,\text{A}$$

2. 对 $i_L(t)$ 求导：

   $$\frac{di_L(t)}{dt} = D_2 e^{-\alpha t} - \alpha (D_1 + D_2 t) e^{-\alpha t}$$

   代入 $t = 0^+$：

   $$\frac{di_L(0^+)}{dt} = D_2 - \alpha D_1$$

   $$-40,000 = D_2 - 100,000 \times 0.1 \implies D_2 = -40,000 + 10,000 = -30,000\,\text{A/s}$$

#### 第五步：写出最终响应函数

$$i_L(t) = (0.1 - 30,000 t) e^{-100,000 t}\,\text{A} \quad (t \ge 0)$$

### 例题 4：并联 RLC 自然响应（EX 3.18）

*(修正自 PDF Page 65)*

**【题目描述】** 在如图所示电路中，在 $t < 0$ 时已达稳态。在 $t = 0$ 时，两个开关同时发生动作：左侧开关接通，右侧开关断开。已知电阻 $R_1 = 1\,\Omega$，$R_2 = 100\,\Omega$，$R_3 = 500\,\Omega$，$L = 62.5\,\text{mH}$，$C = 1\,\mu\text{F}$。 求 $t \ge 0^+$ 时的输出节点电压 $v_o(t)$。

```
              t = 0 (闭合)               t = 0 (断开)
           ┌─────o  o─────┬─────────┬─────o/ o─────┬─────────┐
           │              │         │              │         │
          [+]            R2        电阻           电感       │
     15V  源             100Ω      R3             62.5mH     C 1μF
          [-]             │        500Ω            │         │
           │              ├─────────┴──────────────┼─────────┤ (vo)
           │              │                        │         │
           │             电流源                    │         │
           │             60mA                      │         │
           └──────────────┴────────────────────────┴─────────┘
```

**【解题步骤】**

#### 第一步：分析旧电路 ($t < 0$) 确定初值

在 $t < 0$ 时，电路处于直流稳态。右侧开关是闭合的，左侧开关是断开的。 通过直流分析：

- 电容 $C$ 处于开路状态，电感 $L$ 处于短路状态。

- 分析可知，电容电压初值和电感电流初值为：

  $$v_C(0^-) = 10\,\text{V}$$

  $$i_L(0^-) = 20\,\text{mA}$$

  根据连续性原理：

  $$v_C(0^+) = v_C(0^-) = 10\,\text{V}$$

  $$i_L(0^+) = i_L(0^-) = 20\,\text{mA}$$

#### 第二步：分析新电路 ($t > 0$)

在 $t > 0$ 时，左侧开关接通，右侧开关断开。输出端 $v_o(t)$ 所在的电路变为一个**无源并联 RLC 电路**，由 $R_3 = 500\,\Omega$、$L = 62.5\,\text{mH}$、$C = 1\,\mu\text{F}$ 组成。 输出电压即为电容电压：$v_o(t) = v_C(t)$。因此：

$$v_o(0^+) = v_C(0^+) = 10\,\text{V}$$

下面利用 KCL 确定一阶导数初值 $\frac{dv_o(0^+)}{dt}$。 在并联主节点上列写 KCL 方程：

$$i_C(0^+) + i_L(0^+) + \frac{v_o(0^+)}{R_3} = 0$$

$$C \frac{dv_o(0^+)}{dt} + i_L(0^+) + \frac{v_o(0^+)}{R_3} = 0$$

代入具体数值：

$$10^{-6} \frac{dv_o(0^+)}{dt} + 20 \times 10^{-3} + \frac{10}{500} = 0$$

$$10^{-6} \frac{dv_o(0^+)}{dt} + 0.02 + 0.02 = 0 \implies 10^{-6} \frac{dv_o(0^+)}{dt} = -0.04$$

解得：

$$\frac{dv_o(0^+)}{dt} = -40,000\,\text{V/s}$$

#### 第三步：判定阻尼状态

对于并联 RLC 电路：

$$\alpha = \frac{1}{2R_3 C} = \frac{1}{2 \times 500 \times 10^{-6}} = 1000\,\text{rad/s}$$

$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{62.5 \times 10^{-3} \times 10^{-6}}} = \sqrt{1.6 \times 10^7} = 4000\,\text{rad/s}$$

由于 $\alpha < \omega_0$ **(**$1000 < 4000$**)**，电路处于欠阻尼（Underdamped）状态！

阻尼谐振频率 $\omega_d$ 为：

$$\omega_d = \sqrt{\omega_0^2 - \alpha^2} = \sqrt{4000^2 - 1000^2} = \sqrt{1.5 \times 10^7} \approx 3872.98\,\text{rad/s}$$

#### 第四步：求解特征常数

欠阻尼的响应形式为：

$$v_o(t) = e^{-\alpha t} \left( B_1 \cos\omega_d t + B_2 \sin\omega_d t \right) = e^{-1000 t} \left( B_1 \cos(3873 t) + B_2 \sin(3873 t) \right)$$

1. 代入初值 $v_o(0^+) = 10\,\text{V}$：

   $$v_o(0^+) = B_1 = 10\,\text{V}$$

2. 求导并代入导数初值 $\frac{dv_o(0^+)}{dt} = -40,000$：

   $$\frac{dv_o(0^+)}{dt} = -\alpha B_1 + \omega_d B_2 = -40,000$$

   $$-1000 \times 10 + 3873 B_2 = -40,000 \implies 3873 B_2 = -30,000 \implies B_2 \approx -7.75\,\text{V}$$

#### 第五步：得出最终表达式

$$v_o(t) = e^{-1000t} \left[ 10 \cos(3873t) - 7.75 \sin(3873t) \right]\,\text{V} \quad (t \ge 0)$$

# 第三部分：高阶与多回路电路的系统化解法

当电路包含多个回路且存在多个储能元件，无法通过简单的串并联进行化简时，列写的 KCL/KVL 会形成**联立微分方程组**。此时，使用常规代入消元法极易出错。

## 3.1 微分算子法（Big D Method）的系统应用

**微分算子** $D$ 是一种将微积分运算转化为代数运算的强有力工具。

### 1. 算子定义与代数化规则

我们定义微分算子 $D$ 为对时间的导数：

$$D \equiv \frac{d}{dt} \quad \text{及} \quad D^2 \equiv \frac{d^2}{dt^2}$$

由此，积分运算可以形式化地记为：

$$\frac{1}{D} \equiv \int dt$$

通过引入 $D$，一阶、二阶微分方程可以写成代数多项式的形式。 例如，微分方程 $\frac{d^2y}{dt^2} + 3\frac{dy}{dt} + 2y = f(t)$ 可以直接写为：

$$(D^2 + 3D + 2)y = f(t)$$

### 2. 利用 Big D Method 求解联立方程组的标准步骤

面对包含 $i_1(t)$ 和 $i_2(t)$ 的联立微分方程组时，求解步骤如下：

```
┌────────────────────────────────────────────────────────┐
│             步骤一：将微分方程组用 D 算子重写            │
│ 将所有 d/dt 替换为 D，整理为类似二元一次方程组的形式：   │
│ A(D) * i_1 + B(D) * i_2 = f_1(t)                       │
│ C(D) * i_1 + E(D) * i_2 = f_2(t)                       │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│            步骤二：代数消元 (利用克拉默法则)             │
│ 像对待常数一样对待 D 多项式，消去非目标变量 (例如 i_2)， │
│ 从而得到一个只包含单一变量 (例如 i_1) 的高阶微分方程： │
│ [A(D)*E(D) - B(D)*C(D)] * i_1 = E(D)*f_1(t) - B(D)*f_2(t)│
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│          步骤三：展开算子多项式，回归标准解法            │
│ 1. 将 D 重新展开为对时间 t 的导数形式。                │
│ 2. 求解该高阶齐次微分方程的特征根。                    │
│ 3. 根据初始条件确定响应常数。                          │
└────────────────────────────────────────────────────────┘
```

### 3. Big D Method 经典例题分析

*(修正自 Lec 21 笔记)*

**【题目描述】** 已知某一双回路耦合电路在开关动作后的联立微分方程组为：

$$(D+6)i_1 - 2i_2 = 12 \quad \text{--- (方程 1)}$$

$$-2Di_1 + (2D+2)i_2 = 0 \quad \text{--- (方程 2)}$$

试求出关于 $i_1(t)$ 的独立微分方程。

**【解题步骤】**

为了消去变量 $i_2$，我们需要对两个方程进行代数算子操作，使 $i_2$ 前面的系数多项式一致：

1. **方程 1 乘以** $(D+1)$（注意：对常数项 $12$ 也要进行算子操作）：

   $$(D+1)(D+6)i_1 - 2(D+1)i_2 = (D+1)(12)$$

   因为 $D(12) = \frac{d(12)}{dt} = 0$，所以右侧变为：

   $$(D+1)(12) = 0 + 12 = 12$$

   整理得到：

   $$(D^2 + 7D + 6)i_1 - (2D+2)i_2 = 12 \quad \text{--- (方程 1')}$$

2. **将方程 2 变形**，使其 $i_2$ 项系数与方程 1' 相同：

   $$-2Di_1 + (2D+2)i_2 = 0 \implies (2D+2)i_2 = 2Di_1 \quad \text{--- (方程 2')}$$

3. **将方程 2' 直接代入方程 1' 中**（实现消元）：

   $$(D^2 + 7D + 6)i_1 - 2Di_1 = 12$$

4. **合并同类项**：

   $$(D^2 + 5D + 6)i_1 = 12$$

5. **将** $D$ **算子还原为微分符号**：

   $$\boxed{\frac{d^2i_1(t)}{dt^2} + 5\frac{di_1(t)}{dt} + 6i_1(t) = 12}$$

**【后续求解思路提示】** 通过 Big D Method，我们将复杂的联立方程完美转化为了一个标准的二阶常系数非齐次微分方程：

- **特征方程：** $s^2 + 5s + 6 = 0 \implies (s+2)(s+3) = 0 \implies s_1 = -2, s_2 = -3$（过阻尼状态）。
- **齐次解：** $i_{1h}(t) = A_1 e^{-2t} + A_2 e^{-3t}$。
- **特解：** 令 $\frac{d^2i_1}{dt^2} = \frac{di_1}{dt} = 0$，得稳态特解 $i_{1p}(t) = \frac{12}{6} = 2\,\text{A}$。
- **完全解：** $i_1(t) = 2 + A_1 e^{-2t} + A_2 e^{-3t}$。最后代入初值求解 $A_1, A_2$ 即可。

# 总结：一阶与二阶电路分析核心心智模型对照

| 维度             | 一阶电路 (RC / RL)                                       | 二阶电路 (RLC)                                               |
| ---------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| **控制微分方程** | 一阶常微分方程：$\frac{dx}{dt} + \frac{1}{\tau}x = f(t)$ | 二阶常微分方程：$\frac{d^2x}{dt^2} + 2\alpha \frac{dx}{dt} + \omega_0^2 x = f(t)$ |
| **响应决定要素** | 三要素：$x(0^+)$，$x(\infty)$，$\tau$                    | 五要素：$x(0^+)$，$\frac{dx(0^+)}{dt}$，$x(\infty)$，$\alpha$，$\omega_0$ |
| **过渡状态判定** | 唯一单调衰减曲线，由 $\tau$ 决定速度                     | 三种阻尼状态：过阻尼、临界阻尼、欠阻尼                       |
| **物理本质**     | 单一储能元件与电阻的能量耗散过程                         | 两个储能元件之间能量的循环交换与电阻耗散                     |
| **复杂系统工具** | 戴维宁等效、超节点/超网孔                                | 状态变量法、微分算子法（Big D Method）                       |
