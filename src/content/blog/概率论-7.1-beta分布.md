# 概率论与贝叶斯推断专题：贝塔分布（Beta Distribution）深度解析与应用笔记

本笔记系统性地整理了贝塔分布（Beta Distribution）的数学基础、统计性质、几何直观、贝叶斯共轭先验推断，并结合经典例题进行深度剖析。

## 一、 贝塔分布的基本定义与数学背景

### 1. 为什么需要贝塔分布？

在概率论和统计学中，我们经常需要对“概率”本身进行建模。例如：

- 一枚硬币投出正面的概率 $\theta$ 是多少？
- 某广告的点击率（CTR） $\theta$ 是多少？
- 某系统的在线率（Uptime） $\theta$ 是多少？

由于 $\theta$ 代表概率，其取值范围必须严格限定在区间 $[0, 1]$ 内。普通的连续分布（如正态分布、指数分布）的支撑集通常为无穷区间，无法直接用于对概率参数进行建模。**贝塔分布（Beta Distribution）就是专门针对定义在区间** $[0, 1]$ **上的连续型随机变量进行建模的族群。**

### 2. 概率密度函数（PDF）

若随机变量 $X$ 服从参数为 $\alpha$ 和 $\beta$ 的贝塔分布，记作：

$$X \sim \text{Beta}(\alpha, \beta)$$

其概率密度函数（PDF）定义为：

$$f(x; \alpha, \beta) = \begin{cases} \frac{1}{B(\alpha, \beta)} x^{\alpha-1} (1-x)^{\beta-1} & \text{if } 0 \le x \le 1 \\ 0 & \text{otherwise} \end{cases}$$

其中：

- $\alpha > 0$ 和 $\beta > 0$ 是分布的**形状参数**（在贝叶斯推断中常被称为**超参数**）。
- $B(\alpha, \beta)$ 是**贝塔函数（Beta Function）**，作为归一化常数，用以确保概率密度的全区间积分为 $1$。

### 3. 贝塔函数与伽马函数的关系

贝塔函数定义为如下积分：

$$B(\alpha, \beta) = \int_0^1 x^{\alpha-1} (1-x)^{\beta-1} dx$$

在实际计算中，我们利用它与伽马函数（Gamma Function）的恒等关系来进行求解：

$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$

其中伽马函数 $\Gamma(z)$ 的定义为：

$$\Gamma(z) = \int_0^\infty t^{z-1} e^{-t} dt, \quad z > 0$$

**伽马函数的核心性质：**

- 对任意实数 $z > 0$，有 $\Gamma(z+1) = z\Gamma(z)$。

- 当 $n$ 为正整数时，有 $\Gamma(n) = (n-1)!$。

- 结合上述性质，当 $\alpha$ 和 $\beta$ 为正整数时，贝塔函数可化简为阶乘形式：

  $$B(\alpha, \beta) = \frac{(\alpha-1)!(\beta-1)!}{(\alpha+\beta-1)!}$$

## 二、 贝塔分布的重要统计性质及数学推导

手写笔记中直接给出了期望、方差和众数的结论，下面补充其**严谨的数学推导过程**。

### 1. 数学期望 $E[X]$ 的推导

根据连续型随机变量期望的定义：

$$E[X] = \int_0^1 x \cdot f(x; \alpha, \beta) dx = \int_0^1 x \cdot \frac{1}{B(\alpha, \beta)} x^{\alpha-1} (1-x)^{\beta-1} dx$$

我们将常数项提出，并将积分项合并：

$$E[X] = \frac{1}{B(\alpha, \beta)} \int_0^1 x^{\alpha} (1-x)^{\beta-1} dx$$

注意到积分部分恰好是参数为 $\alpha+1$ 和 $\beta$ 的贝塔函数 $B(\alpha+1, \beta)$ 的定义式：

$$E[X] = \frac{B(\alpha+1, \beta)}{B(\alpha, \beta)}$$

利用伽马函数的关系进行展开：

$$E[X] = \frac{\Gamma(\alpha+1)\Gamma(\beta)}{\Gamma(\alpha+1+\beta)} \cdot \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}$$

利用关系式 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha)$ 以及 $\Gamma(\alpha+\beta+1) = (\alpha+\beta)\Gamma(\alpha+\beta)$ 代入化简：

$$E[X] = \frac{\alpha\Gamma(\alpha)\Gamma(\beta)}{(\alpha+\beta)\Gamma(\alpha+\beta)} \cdot \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} = \frac{\alpha}{\alpha+\beta}$$

**结论：**

$$E[X] = \frac{\alpha}{\alpha+\beta}$$

### 2. 方差 $Var(X)$ 的推导

利用方差计算公式 $Var(X) = E[X^2] - (E[X])^2$，我们先计算二阶原点矩 $E[X^2]$：

$$E[X^2] = \int_0^1 x^2 \cdot \frac{1}{B(\alpha, \beta)} x^{\alpha-1} (1-x)^{\beta-1} dx = \frac{1}{B(\alpha, \beta)} \int_0^1 x^{\alpha+1} (1-x)^{\beta-1} dx$$

$$E[X^2] = \frac{B(\alpha+2, \beta)}{B(\alpha, \beta)}$$

代入伽马函数展开：

$$E[X^2] = \frac{\Gamma(\alpha+2)\Gamma(\beta)}{\Gamma(\alpha+\beta+2)} \cdot \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}$$

由于 $\Gamma(\alpha+2) = (\alpha+1)\alpha\Gamma(\alpha)$ 且 $\Gamma(\alpha+\beta+2) = (\alpha+\beta+1)(\alpha+\beta)\Gamma(\alpha+\beta)$：

$$E[X^2] = \frac{\alpha(\alpha+1)}{(\alpha+\beta)(\alpha+\beta+1)}$$

代入方差公式：

$$Var(X) = E[X^2] - (E[X])^2 = \frac{\alpha(\alpha+1)}{(\alpha+\beta)(\alpha+\beta+1)} - \left( \frac{\alpha}{\alpha+\beta} \right)^2$$

提取公因式 $\frac{\alpha}{\alpha+\beta}$：

$$Var(X) = \frac{\alpha}{\alpha+\beta} \left[ \frac{\alpha+1}{\alpha+\beta+1} - \frac{\alpha}{\alpha+\beta} \right]$$

对括号内进行通分：

$$Var(X) = \frac{\alpha}{\alpha+\beta} \cdot \frac{(\alpha+1)(\alpha+\beta) - \alpha(\alpha+\beta+1)}{(\alpha+\beta)(\alpha+\beta+1)}$$

$$Var(X) = \frac{\alpha}{\alpha+\beta} \cdot \frac{(\alpha^2 + \alpha\beta + \alpha + \beta) - (\alpha^2 + \alpha\beta + \alpha)}{(\alpha+\beta)(\alpha+\beta+1)}$$

$$Var(X) = \frac{\alpha}{\alpha+\beta} \cdot \frac{\beta}{(\alpha+\beta)(\alpha+\beta+1)} = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

**结论：**

$$Var(X) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

### 3. 众数 $\text{Mode}(X)$ 的推导

众数是使概率密度函数 $f(x)$ 达到最大值的 $x$。设 $g(x) = \ln f(x)$，对 $f(x)$ 求最值等价于对 $g(x)$ 求最值（假定 $\alpha > 1, \beta > 1$）：

$$g(x) = \ln \left( \frac{1}{B(\alpha, \beta)} \right) + (\alpha-1)\ln x + (\beta-1)\ln(1-x)$$

对 $x$ 求一阶导数并令其为 $0$：

$$g'(x) = \frac{\alpha-1}{x} - \frac{\beta-1}{1-x} = 0$$

$$\frac{\alpha-1}{x} = \frac{\beta-1}{1-x}$$

$$(\alpha-1)(1-x) = (\beta-1)x$$

$$\alpha - 1 - \alpha x + x = \beta x - x$$

$$\alpha - 1 = (\alpha + \beta - 2)x$$

$$x = \frac{\alpha-1}{\alpha+\beta-2}$$

由于在此处二阶导数 $g''(x) = -\frac{\alpha-1}{x^2} - \frac{\beta-1}{(1-x)^2} < 0$（当 $\alpha > 1, \beta > 1$），该点确为极大值点。

**结论：** 当 $\alpha > 1$ 且 $\beta > 1$ 时，众数为：

$$\text{Mode}(X) = \frac{\alpha-1}{\alpha+\beta-2}$$

## 三、 贝塔分布的几何直观与物理意义

### 1. 形状参数对 PDF 曲线的影响

| 参数条件                | 分布图景与特征描述                                                 | 物理直观                                                           |
| ----------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| $\alpha = 1, \beta = 1$ | 概率密度退化为一条水平直线，即 $\text{Uniform}(0,1)$。             | **完全无信息（Flat Prior）**。对取值区间内任何位置的概率一视同仁。 |
| $\alpha = \beta > 1$    | 曲线关于 $x = 0.5$ 完美对称。若 $\alpha, \beta$ 越大，峰值越尖锐。 | 认为成功与失败的可能性均等，且观测数据量越大，确信度越高。         |
| $\alpha > \beta > 1$    | 曲线向右倾斜，峰值（众数）偏向 $1$ 的一侧。                        | 认为成功的概率更高。                                               |
| $\alpha < \beta > 1$    | 曲线向左倾斜，峰值（众数）偏向 $0$ 的一侧。                        | 认为失败的概率更高。                                               |
| $\alpha < 1, \beta < 1$ | 曲线呈双峰 U 形（在 $0$ 和 $1$ 处极度陡峭）。                      | 认为概率极可能接近 $0$ 或接近 $1$（非黑即白）。                    |

### 2. 浓度效应（Concentration Effect）

观察期望 $E[X] = \frac{\alpha}{\alpha+\beta}$ 与方差 $Var(X) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$。 当我们将 $\alpha$ 和 $\beta$ 按比例同倍数扩大（例如从 $\text{Beta}(2, 2)$ 变为 $\text{Beta}(20, 20)$）：

- 期望保持不变（均为 $0.5$）。
- 方差会显着减小（从 $\frac{4}{16 \times 5} = 0.05$ 减小到 $\frac{400}{1600 \times 41} \approx 0.006$）。 这直观地展示了：**参数的绝对值越大，代表我们的“先验知识”越丰富、越具有确定性，概率分布曲线也会随之在均值附近高度收敛。**

## 四、 贝叶斯推断与共轭先验（Conjugate Prior）

在贝叶斯统计学中，贝塔分布之所以具有崇高的地位，是因为它是**伯努利分布/二项分布的共轭先验**。

### 1. 什么是共轭先验？

若一个先验分布与似然函数结合后，所得到的后验分布与先验分布属于同一种概率分布族，则该先验分布被称为似然函数的**共轭先验（Conjugate Prior）**。它的优势在于：**我们可以通过简单的参数加减法直接写出后验分布的形式，而无需计算极其复杂的贝叶斯分母积分。**

### 2. 贝塔-二项共轭性的严格证明

设我们要估计事件成功的概率 $\theta$。

1. **先验分布（Prior）**：假设 $\theta$ 服从贝塔分布：

   $$\theta \sim \text{Beta}(a, b) \implies P(\theta) = \frac{1}{B(a, b)} \theta^{a-1} (1-\theta)^{b-1}$$

2. **似然函数（Likelihood）**：进行 $n$ 次独立的伯努利试验，观测到 $k$ 次成功， $n-k$ 次失败。其似然函数符合二项分布：

   $$P(\text{Data} \mid \theta) = \binom{n}{k} \theta^k (1-\theta)^{n-k}$$

3. **后验分布（Posterior）**：根据贝叶斯定理：

   $$P(\theta \mid \text{Data}) = \frac{P(\text{Data} \mid \theta) P(\theta)}{P(\text{Data})}$$

由于分母 $P(\text{Data})$ 是一个与 $\theta$ 无关的归一化常数，我们可以省略它写成正比例形式：

$$P(\theta \mid \text{Data}) \propto P(\text{Data} \mid \theta) P(\theta)$$

将先验与似然代入：

$$P(\theta \mid \text{Data}) \propto \left[ \binom{n}{k} \theta^k (1-\theta)^{n-k} \right] \cdot \left[ \frac{1}{B(a, b)} \theta^{a-1} (1-\theta)^{b-1} \right]$$

在关于 $\theta$ 的函数关系中，常数项（不含 $\theta$ 的项，如 $\binom{n}{k}$ 和 $\frac{1}{B(a, b)}$）可以并入比例常数中：

$$P(\theta \mid \text{Data}) \propto \theta^k (1-\theta)^{n-k} \cdot \theta^{a-1} (1-\theta)^{b-1}$$

合并底数相同的幂指数：

$$P(\theta \mid \text{Data}) \propto \theta^{(a+k)-1} (1-\theta)^{(b+n-k)-1}$$

**观察上述形式：** 它的数学结构完全等同于一个参数为 $a+k$ 和 $b+n-k$ 的贝塔分布。由于概率密度函数的全区间积分必须为 $1$，我们可以唯一地确定其归一化常数，从而直接写出后验概率密度的精确表达式：

$$P(\theta \mid \text{Data}) = \frac{1}{B(a+k, b+n-k)} \theta^{(a+k)-1} (1-\theta)^{(b+n-k)-1}$$

即：

$$\theta \mid \text{Data} \sim \text{Beta}(a + k, b + n - k)$$

### 3. 先验参数 $a, b$ 的物理意义：伪计数（Pseudo-counts）

通过共轭推导结果，我们可以将超参数 $a$ 和 $b$ 赋予极其直观的物理意义：

- $a$ 可以看作我们在开始实验前，心理上**虚拟的成功次数（Pseudo-successes）**。
- $b$ 可以看作我们在开始实验前，心理上**虚拟的失败次数（Pseudo-failures）**。
- $a+b$ 代表先验的**虚拟总样本量**。

当我们真正观测到 $k$ 次成功和 $f = n-k$ 次失败时，我们只需要简单地：

$$\text{新参数 } a' = a + k$$

$$\text{新参数 } b' = b + f$$

这种简便的更新方式使得贝塔分布在大数据分析和实时在线学习（如多臂老虎机问题汤普森采样算法）中被广泛应用。

## 五、 经典例题与深度解析

### 例题 1：硬币投掷问题（无信息先验/均匀先验）

**【题目】** 我们有一枚硬币，其投出正面的概率 $\theta$ 未知。

1. 若由于缺乏任何物理常识，我们假定其初试先验是一个均匀分布 $\text{Uniform}(0,1)$。
2. 随后我们进行了 10 次投掷，发现有 8 次正面朝上，2 次反面朝上。
3. 请计算该硬币投出正面概率 $\theta$ 的后验分布、后验均值（Posterior Mean），并将结果与最大似然估计（MLE）的结果进行对比。

**【解析】**

1. **设定先验**： 均匀分布 $\text{Uniform}(0,1)$ 对应于 $\text{Beta}(1,1)$ 分布（代入 $\alpha=1, \beta=1$ 可得 $f(x)=1$）。因此，先验超参数为：

   $$a = 1, \quad b = 1$$

2. **收集数据**： 成功次数（正面） $k = 8$，失败次数（反面） $f = 2$。

3. **求解后验分布**： 根据贝塔-二项共轭性，后验分布为：

   $$\theta \mid \text{Data} \sim \text{Beta}(a + k, b + f) = \text{Beta}(1 + 8, 1 + 2) = \text{Beta}(9, 3)$$

4. **计算后验均值**：

   $$E[\theta \mid \text{Data}] = \frac{a'}{a'+b'} = \frac{9}{9+3} = \frac{9}{12} = 0.75$$

5. **对比最大似然估计（MLE）**： 频数学派的最大似然估计直接根据实验数据计算：

   $$\theta_{\text{MLE}} = \frac{k}{n} = \frac{8}{10} = 0.8$$

**【物理意义分析】** 后验均值（$0.75$）相比于 MLE（$0.8$）更偏向于 $0.5$。这是因为先验分布 $\text{Beta}(1,1)$ 相当于注入了 $2$ 次虚拟试验（1次成功，1次失败），起到了平滑（Smoothing）的作用，防止了在小样本情况下因为偶然误差得出极端结论（比如投掷2次均为正面，MLE会给出 $1.0$ 的荒谬概率，而贝叶斯估计则会将其往先验拉回）。

### 例题 2：广告点击率（CTR）预测（有信息先验）

**【题目】** 某互联网公司的算法工程师需要评估新上线广告的点击率（CTR） $\theta$。

1. 根据历史海量同类型广告的数据积淀，广告的平均点击率通常为 $10\%$，且表现非常稳定。工程师使用 $\text{Beta}(10, 90)$ 作为先验分布来刻画这种确信度。
2. 新广告上线后，展示给 100 位用户，其中有 15 位用户点击了广告。
3. 请计算新广告点击率 $\theta$ 的后验分布、后验均值，并探讨有信息先验对估计结果的影响。

**【解析】**

1. **分析先验**： 先验分布 $\theta \sim \text{Beta}(10, 90)$。
   - 先验期望 $E[\theta] = \frac{10}{10+90} = 0.1$ （即历史均值 $10\%$）。
   - 相当于工程师在实验开始前，已经默认拥有了 100 次历史广告展示，其中有 10 次点击、90 次未点击的丰富先验经验。

2. **收集实验数据**： 新增展示次数 $n = 100$，点击（成功） $k = 15$，未点击（失败） $f = 100 - 15 = 85$。

3. **计算后验分布**：

   $$\theta \mid \text{Data} \sim \text{Beta}(a + k, b + f) = \text{Beta}(10 + 15, 90 + 85) = \text{Beta}(25, 175)$$

4. **计算后验期望与对比**：
   - **后验均值**：

     $$E[\theta \mid \text{Data}] = \frac{25}{25+175} = \frac{25}{200} = 0.125 \quad (12.5\%)$$

   - **最大似然估计（MLE）**：

     $$\theta_{\text{MLE}} = \frac{15}{100} = 0.15 \quad (15\%)$$

**【物理意义分析】** 在该场景中，新数据表现出异常优异的点击率（$15\%$）。然而，由于工程师持有一个高确信度的先验（等效于 100 次历史样本），后验均值被“锚定”在了 $12.5\%$。 它完美地综合了两个维度的信息：

$$E[\theta \mid \text{Data}] = \frac{10 \ (\text{先验成功}) + 15 \ (\text{实际成功})}{100 \ (\text{先验总量}) + 100 \ (\text{实际总量})} = 12.5\%$$

这可以防止模型因为小规模测试（仅 100 次展示）的统计波动而盲目高估该广告的真实点击率，在工程实际中能带来极佳的鲁棒性。

### 例题 3：先验概率计算与后验分析（新增综合计算题）

**【题目】** 已知某一工业制造产品的合格率 $\theta$ 服从先验分布 $\text{Beta}(3, 2)$。

1. 计算该产品的合格率 $\theta$ 超过 $50\%$ 的先验概率。
2. 现进行一次随机抽样检验，抽检了 3 个样品，发现其中有 2 个合格品、1 个不合格品。求合格率 $\theta$ 的后验分布。
3. 计算该后验分布的均值与众数。

**【解析】**

#### 第一问：计算 $P(\theta > 0.5)$

已知 $\theta \sim \text{Beta}(3, 2)$。 首先确定归一化常数 $\frac{1}{B(3, 2)}$：

$$B(3, 2) = \frac{\Gamma(3)\Gamma(2)}{\Gamma(3+2)} = \frac{2! \times 1!}{4!} = \frac{2 \times 1}{24} = \frac{1}{12}$$

所以其先验概率密度函数（PDF）为：

$$f(\theta) = 12 \theta^{3-1} (1-\theta)^{2-1} = 12 \theta^2 (1-\theta) = 12\theta^2 - 12\theta^3, \quad 0 \le \theta \le 1$$

我们需要计算在区间 $[0.5, 1]$ 上的定积分：

$$P(\theta > 0.5) = \int_{0.5}^1 (12\theta^2 - 12\theta^3) d\theta$$

求原函数：

$$F(\theta) = \int (12\theta^2 - 12\theta^3) d\theta = 4\theta^3 - 3\theta^4$$

代入上下限进行计算：

$$P(\theta > 0.5) = F(1) - F(0.5)$$

$$F(1) = 4(1)^3 - 3(1)^4 = 4 - 3 = 1$$

$$F(0.5) = 4(0.5)^3 - 3(0.5)^4 = 4(0.125) - 3(0.0625) = 0.5 - 0.1875 = 0.3125$$

$$P(\theta > 0.5) = 1 - 0.3125 = 0.6875$$

**答案：** 该产品合格率超过 $50\%$ 的先验概率为 $68.75\%$。

#### 第二问：求后验分布

- 先验超参数：$a = 3, b = 2$

- 观测数据：合格品（成功） $k = 2$，不合格品（失败） $f = 1$ 根据共轭更新公式，后验分布参数为：

  $$a' = a + k = 3 + 2 = 5$$

  $$b' = b + f = 2 + 1 = 3$$

**答案：** 更新后的后验分布为 $\theta \mid \text{Data} \sim \text{Beta}(5, 3)$。

#### 第三问：计算后验分布的期望（均值）与众数

对于后验分布 $\text{Beta}(5, 3)$：

1. **后验期望**：

   $$E[\theta \mid \text{Data}] = \frac{a'}{a'+b'} = \frac{5}{5+3} = \frac{5}{8} = 0.625$$

2. **后验众数**（由于 $a' = 5 > 1, b' = 3 > 1$）：

   $$\text{Mode}(\theta \mid \text{Data}) = \frac{a'-1}{a'+b'-2} = \frac{5-1}{5+3-2} = \frac{4}{6} = \frac{2}{3} \approx 0.667$$

**答案：** 后验均值为 $0.625$，后验众数约为 $0.667$。

## 六、 拓展延伸：顺序统计量（Order Statistics）与贝塔分布的联系

这是经典概率论中极其美妙的一个定理，将贝塔分布与连续均匀分布紧密联系在了一起。

### 定理内容

设 $U_1, U_2, \dots, U_n$ 是从连续均匀分布 $\text{Uniform}(0, 1)$ 中独立同分布（i.i.d.）采样出的 $n$ 个随机变量。 若将这 $n$ 个随机变量从小到大进行排序，得到**顺序统计量**：

$$U_{(1)} \le U_{(2)} \le \dots \le U_{(k)} \le \dots \le U_{(n)}$$

则第 $k$ 小的变量 $U_{(k)}$ 严格服从贝塔分布：

$$U_{(k)} \sim \text{Beta}(k, n - k + 1)$$

### 直观物理证明（微元法）

为什么会有这个结论？我们推导 $U_{(k)}$ 落入微小区间 $[x, x + dx]$ 的概率 $P(x \le U_{(k)} \le x + dx)$：

1. 要让第 $k$ 小的数恰好落在 $[x, x + dx]$ 处：
   - 必须有 $k-1$ 个样本落在区间 $[0, x)$ 内。因为每个 $U_i$ 落在该区间的概率为 $x$，根据多项分布，这部分的概率贡献为 $x^{k-1}$。
   - 必须恰好有 $1$ 个样本落在 $[x, x + dx]$ 内。其概率为 $dx$。
   - 剩下的 $n - k$ 个样本必须全部落在 $(x + dx, 1]$ 内。每个样本落在此处的概率约为 $1-x$，其概率贡献为 $(1-x)^{n-k}$。

2. 考虑这三组样本在整个 $n$ 样本序列中的排列组合数。我们有 $n$ 个样本，选出 $k-1$ 个、 $1$ 个、 $n-k$ 个，其组合数（多项式系数）为：

   $$\frac{n!}{(k-1)! \ 1! \ (n-k)!}$$

将所有部分相乘，得到概率密度微元：

$$f_{U_{(k)}}(x)dx \approx \frac{n!}{(k-1)!(n-k)!} x^{k-1} (1-x)^{n-k} dx$$

我们利用伽马函数关系重写系数：

$$\frac{n!}{(k-1)!(n-k)!} = \frac{\Gamma(n+1)}{\Gamma(k)\Gamma(n-k+1)} = \frac{1}{B(k, n-k+1)}$$

因此，其概率密度函数为：

$$f_{U_{(k)}}(x) = \frac{1}{B(k, n-k+1)} x^{k-1} (1-x)^{(n-k+1)-1}$$

这正好是 $\text{Beta}(k, n-k+1)$ 的概率密度函数！

**例子：** 若我们在 $\text{Uniform}(0,1)$ 中随机抽取 5 个样本，其中**中位数**（即第 3 小的数 $U_{(3)}$）的概率分布为：

$$U_{(3)} \sim \text{Beta}(3, 5-3+1) = \text{Beta}(3, 3)$$

其期望为：

$$E[U_{(3)}] = \frac{3}{3+3} = 0.5$$

这完全符合我们的直观认知。
