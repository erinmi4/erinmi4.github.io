# 复数项级数与幂级数系统学习笔记

本笔记对应复变函数中“级数”这一章的基础与核心内容。我们将沿着“复数序列 $\to$ 复数项级数 $\to$ 幂级数 $\to$ 收敛半径求法”的逻辑线索，系统地梳理基本概念、核心定理与经典例题。

## 第一部分：复数序列及其极限

在讨论无限项相加的级数之前，我们必须先明确最基础的基石——**复数序列**及其极限。级数的收敛性本质上就是其部分和序列的极限问题。

### 1. 复数序列的定义

设有一排按照确定顺序排列的复数：

$$z_1, z_2, \dots, z_n, \dots \quad (\text{简记为 } \{z_n\})$$

其中每一项都是复数，$z_n = a_n + i b_n$（$a_n, b_n \in \mathbb{R}$），则称其为**复数序列**。

### 2. 复数序列极限的几何与代数定义

- **几何定义（**$\varepsilon-N$ **语言）：** 若存在一个确定的复常数 $z_0$，对于任意给定的正数 $\varepsilon > 0$，总存在一个正整数 $N$，当 $n > N$ 时，恒有：
    
    $$|z_n - z_0| < \varepsilon$$
    
    则称复数序列 $\{z_n\}$ 收敛于 $z_0$，记作：
    
    $$\lim_{n \to \infty} z_n = z_0$$
    
    _几何意义：当_ $n$ _充分大时，所有的点_ $z_n$ _都落入以_ $z_0$ _为圆心、_$\varepsilon$ _为半径的圆盘内部。_
    
- **代数充要条件（化归为实数序列极限）：** 设 $z_n = a_n + i b_n$，$z_0 = a + i b$，则：
    
    $$\lim_{n \to \infty} z_n = z_0 \iff \lim_{n \to \infty} a_n = a \quad \text{且} \quad \lim_{n \to \infty} b_n = b$$
    
    这个重要定理允许我们**将复数序列的求极限问题，转化为大家熟知的两个实数序列的求极限问题**。
    

### 【补充简单例题】

**例题：** 讨论序列 $z_n = \frac{n+1}{n} + i \frac{1}{2^n}$ 的收敛性。


**解析：** 令 $a_n = \frac{n+1}{n}$，$b_n = \frac{1}{2^n}$。 因为：

$$\lim_{n \to \infty} a_n = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right) = 1$$$$\lim_{n \to \infty} b_n = \lim_{n \to \infty} \frac{1}{2^n} = 0$$

两者的实部与虚部极限均存在。因此，该复序列收敛，且极限为：

$$\lim_{n \to \infty} z_n = 1 + i \cdot 0 = 1$$

## 第二部分：复数项级数及其敛散性

当我们尝试把复数序列 $\{z_n\}$ 的无限多个项依次相加时，便得到了**复数项级数**。

### 1. 复数项级数的定义

形如以下无限相加的表达式：

$$\sum_{n=1}^{\infty} z_n = z_1 + z_2 + \dots + z_n + \dots$$

称为**复数项级数**。

### 2. 通过部分和序列（Partial Sums）判定敛散性

研究无穷级数的敛散性，最根本的工具就是**部分和**。 设级数的前 $n$ 项和为 $S_n$：

$$S_n = \sum_{k=1}^{n} z_k = z_1 + z_2 + \dots + z_n$$

随着 $n$ 的增加，$\{S_n\}$ 构成了一个新的复数序列，称为**部分和序列**。

- **收敛：** 若部分和序列 $\{S_n\}$ 的极限存在，即 $\lim_{n \to \infty} S_n = S$（$S$ 为复常数），则称该级数**收敛**，其和为 $S$，记作 $\sum_{n=1}^{\infty} z_n = S$。
    
- **发散：** 若极限 $\lim_{n \to \infty} S_n$ 不存在，则称该级数**发散**。
    

### 3. 实部与虚部分解定理

设 $z_n = x_n + i y_n$，则级数 $\sum_{n=1}^{\infty} z_n$ 收敛的充要条件是： **实部级数** $\sum_{n=1}^{\infty} x_n$ **与 虚部级数** $\sum_{n=1}^{\infty} y_n$ **同时收敛。** 若它们收敛于 $X$ 和 $Y$，则级数的和 $S = X + iY$。

### 【经典例题精析】复数等比级数的判定

**例题 1：** 判断级数 $\sum_{n=1}^{\infty} \left(\frac{1}{1+i}\right)^{n-1}$ 的敛散性，若收敛，求其和。

**解析：** 这是一个以 $q = \frac{1}{1+i}$ 为公比的复数等比级数。 写出其前 $n$ 项部分和 $S_n$：

$$S_n = 1 + \frac{1}{1+i} + \left(\frac{1}{1+i}\right)^2 + \dots + \left(\frac{1}{1+i}\right)^{n-1}$$

1. **计算公比** $q$ **的模长：**
    
    $$|q| = \left|\frac{1}{1+i}\right| = \frac{1}{|1+i|} = \frac{1}{\sqrt{1^2 + 1^2}} = \frac{1}{\sqrt{2}}$$
    
    因为 $|q| = \frac{1}{\sqrt{2}} < 1$，所以当 $n \to \infty$ 时：
    
    $$\lim_{n \to \infty} q^n = \lim_{n \to \infty} \left(\frac{1}{1+i}\right)^n = 0$$
2. **利用等比数列求和公式求** $S_n$**：**
    
    $$S_n = \frac{1 - q^n}{1 - q} = \frac{1 - \left(\frac{1}{1+i}\right)^n}{1 - \frac{1}{1+i}}$$
3. **求极限：**
    
    $$\lim_{n \to \infty} S_n = \frac{1 - 0}{1 - \frac{1}{1+i}} = \frac{1}{\frac{(1+i)-1}{1+i}} = \frac{1}{\frac{i}{1+i}} = \frac{1+i}{i}$$
4. **化简结果（分母实数化）：**
    
    $$\frac{1+i}{i} = \frac{(1+i)(-i)}{i(-i)} = \frac{-i - i^2}{1} = \frac{-i + 1}{1} = 1 - i$$

**结论：** 该级数**收敛**，其和为 $1 - i$。

## 第三部分：幂级数的基本概念与阿贝尔定理

从常数项级数向函数项级数过渡时，最简单也最重要的一种形式就是**幂级数**（Power Series）。

### 1. 幂级数的定义

形如：

$$\sum_{n=0}^{\infty} a_n (z - z_0)^n = a_0 + a_1(z - z_0) + a_2(z - z_0)^2 + \dots + a_n(z - z_0)^n + \dots$$

的函数项级数称为**幂级数**。其中：

- $z$ 是复变量；
    
- $z_0$ 是复常数（称为幂级数的中心）；
    
- $a_n$ 是复常数系数。
    

> **化简技巧（平移）：** > 我们可以通过变量代换 $w = z - z_0$，将中心平移到原点。因此，后续我们只需集中研究以下形式的中心在原点的幂级数即可：
> 
> $$\sum_{n=0}^{\infty} a_n z^n$$

### 2. 阿贝尔定理（Abel's Theorem）

这是研究幂级数收敛域的基石定理。

- **定理内容：**
    
    1. 如果级数 $\sum_{n=0}^{\infty} a_n z^n$ 在某点 $z = z_0 \neq 0$ 处**收敛**，那么对于满足 $|z| < |z_0|$ 的一切 $z$，级数都**绝对收敛**。
        
    2. 如果级数 $\sum_{n=0}^{\infty} a_n z^n$ 在某点 $z = z_0$ 处**发散**，那么对于满足 $|z| > |z_0|$ 的一切 $z$，级数都**发散**。
        
- **物理直观与起承转合：** 阿贝尔定理告诉我们：**收敛具有“向内辐射性”（小的更收敛），发散具有“向外扩张性”（大的更发散）**。 正因为这种独特的性质，幂级数的收敛域在复平面上一定呈现出以原点为圆心的**圆盘形状**。这就自然引入了“收敛圆”和“收敛半径”的概念。
    

## 第四部分：收敛半径与收敛圆

### 1. 定义

对于幂级数 $\sum_{n=0}^{\infty} a_n z^n$，必然存在一个非负实数 $R$（$0 \le R \le +\infty$），使得：

- 当 $|z| < R$ 时，级数**绝对收敛**；
    
- 当 $|z| > R$ 时，级数**发散**。 这个圆盘 $|z| < R$ 称为**收敛圆**，$R$ 称为**收敛半径**。
    

> **边界情况（**$|z| = R$**）：** 在收敛圆的边界圆周上，级数的敛散性比较复杂，可能有些点收敛，有些点发散，需要对具体问题进行具体分析。

### 2. 求收敛半径 $R$ 的两大核心方法

这是考试和做题中**最核心、最常考**的计算部分。我们主要有两种审敛法：

#### 方法一：比值法（D'Alembert Test）

设相邻两项系数比值的模之极限为：

$$\lambda = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right|$$

则收敛半径 $R$ 为：

$$R = \begin{cases} \frac{1}{\lambda}, & 0 < \lambda < +\infty \\ +\infty, & \lambda = 0 \\ 0, & \lambda = +\infty \end{cases}$$

#### 方法二：根值法（Cauchy-Hadamard Test）

设系数开 $n$ 次方根的极限为：

$$\lambda = \lim_{n \to \infty} \sqrt[n]{|a_n|}$$

则收敛半径 $R$ 同样为：

$$R = \frac{1}{\lambda} \quad (\text{规定 } \frac{1}{0} = +\infty, \frac{1}{+\infty} = 0)$$

## 第五部分：经典例题实战演练

### 例题 2：求解 $\sum_{n=0}^{\infty} z^n$ 的收敛半径与收敛域

**解析：**

1. 观察级数的系数：$a_n = 1$。
    
2. 使用比值法：
    
    $$\lambda = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| = \lim_{n \to \infty} \left| \frac{1}{1} \right| = 1$$
3. 计算收敛半径：
    
    $$R = \frac{1}{\lambda} = 1$$
4. **部分和验证法（原笔记思路）：** 部分和 $S_n = 1 + z + z^2 + \dots + z^{n-1} = \frac{1 - z^n}{1-z}$。
    
    - 当 $|z| < 1$ 时，$\lim_{n\to\infty} z^n = 0$，故 $\lim_{n\to\infty} S_n = \frac{1}{1-z}$ 存在，级数收敛。
        
    - 当 $|z| \ge 1$ 时，级数的一般项不趋于 $0$，级数发散。
        

**结论：** 收敛半径 $R = 1$，收敛圆（域）为 $|z| < 1$。

### 例题 3：求解 $\sum_{n=1}^{\infty} \frac{n^n}{n!} z^n$ 的收敛半径

_(注：由于分子有_ $n^n$_，分母有阶乘_ $n!$_，两组强增长函数复合，最适合采用**比值法**。)_

**解析：**

1. 提取系数：$a_n = \frac{n^n}{n!}$。
    
2. 计算比值的极限 $\lambda$：
    
    $$\lambda = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| = \lim_{n \to \infty} \frac{\frac{(n+1)^{n+1}}{(n+1)!}}{\frac{n^n}{n!}}$$
3. 利用阶乘性质 $(n+1)! = (n+1) \cdot n!$ 进行约分简化：
    
    $$\lambda = \lim_{n \to \infty} \frac{(n+1)^{n+1} \cdot n!}{(n+1)! \cdot n^n} = \lim_{n \to \infty} \frac{(n+1)^{n+1} \cdot n!}{(n+1) \cdot n! \cdot n^n}$$$$\lambda = \lim_{n \to \infty} \frac{(n+1)^n}{n^n} = \lim_{n \to \infty} \left( \frac{n+1}{n} \right)^n = \lim_{n \to \infty} \left( 1 + \frac{1}{n} \right)^n$$
4. 利用高等数学中的重要极限 $\lim_{n\to\infty} \left(1 + \frac{1}{n}\right)^n = e$：
    
    $$\lambda = e$$
5. 计算收敛半径 $R$：
    
    $$R = \frac{1}{\lambda} = \frac{1}{e}$$

**结论：** 收敛半径 $R = \frac{1}{e}$。

### 例题 4：求解 $\sum_{n=1}^{\infty} \frac{z^n}{n^3}$ 的收敛半径与边界收敛性

_(注：此题展示比值法的基本应用，并作了学术延伸，讨论边界情况。)_

**解析：**

1. 提取系数：$a_n = \frac{1}{n^3}$。
    
2. 计算比值的极限 $\lambda$：
    
    $$\lambda = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| = \lim_{n \to \infty} \frac{\frac{1}{(n+1)^3}}{\frac{1}{n^3}} = \lim_{n \to \infty} \frac{n^3}{(n+1)^3} = \lim_{n \to \infty} \left(\frac{n}{n+1}\right)^3 = 1^3 = 1$$
3. 计算收敛半径 $R$：
    
    $$R = \frac{1}{1} = 1$$
4. **【深度补充】边界收敛性讨论：** 当 $|z| = 1$（即处于收敛圆周上）时，取绝对值级数：
    
    $$\sum_{n=1}^{\infty} \left| \frac{z^n}{n^3} \right| = \sum_{n=1}^{\infty} \frac{|z|^n}{n^3} = \sum_{n=1}^{\infty} \frac{1}{n^3}$$
    
    根据实数级数中的 $p$-级数判别法，当 $p = 3 > 1$ 时，级数收敛。 故该级数在边界 $|z| = 1$ 上不仅收敛，而且是**绝对收敛**的。
    

**结论：** 收敛半径 $R = 1$。

## 💡 总结与方法复习卡

为了在做题时快速找到切入点，请参考以下决策流：

| 级数特征系数 $a_n$                       | 推荐判别法        | 核心公式/极限                         |                             |
| ---------------------------------- | ------------ | ------------------------------- | --------------------------- |
| 含有阶乘 $n!$、混合幂数（如 $\frac{n^n}{n!}$） | **比值法**      | $\lambda = \lim \left\\         | \frac{a_{n+1}}{a_n} \right$ |
| 整体为 $n$ 次幂的形式（如 $c^n, n^n$ 等）      | **根值法（柯西法）** | $\lambda = \lim \sqrt[n]{\\a_n$ |                             |
| 简单的等比或可以直接写出部分和形式                  | **部分和定义法**   | $S_n = \sum z_k$ 并求极限           |                             |

这套逻辑将无缝对接后续更深入的知识点——**泰勒级数 (Taylor Series)** 与 **洛朗级数 (Laurent Series)**。
