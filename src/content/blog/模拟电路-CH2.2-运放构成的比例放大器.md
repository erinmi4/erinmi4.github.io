# 模拟电子技术基础：运放构成的比例放大器

**核心概念**：比例放大器是对输入信号进行比例运算的电路，数学表达式为 $U_o = k \cdot U_i$（$k$ 为比例系数）。 

**基本原理**：如果将运放的反馈网络替换成电阻分压网络，并引入深度负反馈，就可以实现电压的比例放大。

## 一、 同相比例放大器

同相比例放大器是指输入信号 $U_i$ 从运放的同相输入端（+）接入的放大电路。

### 1. 电路结构与推导

![image-20260605104610278](./%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF-CH2.2-%E8%BF%90%E6%94%BE%E6%9E%84%E6%88%90%E7%9A%84%E6%AF%94%E4%BE%8B%E6%94%BE%E5%A4%A7%E5%99%A8.assets/image-20260605104610278.png)

- **信号输入**：接同相端（+）。
- **反馈网络**：输出电压 $U_o$ 经过反馈电阻 $R_2$ 和接地电阻 $R_1$ 分压后，接回**反相端（-）**，构成电压串联负反馈。

**【解答笔记中的疑问】**：您在笔记中写到“这个我不知道，是求 $R_2$ 上电流吗？”

 **解释**：是的，推导过程正是利用了流过 $R_2$ 和 $R_1$ 的电流相等的原理。具体推导如下：

- **虚短**：运放两输入端电压近似相等，因此 $U_- = U_+ = U_i$。

- **虚断**：运放输入端没有电流流入（$I_- = 0$）。因此，流过反馈电阻 $R_2$ 的电流必然等于流过 $R_1$ 的电流。

- **列方程**：

  - 流过 $R_2$ 的电流：$I_{R2} = \frac{U_o - U_-}{R_2} = \frac{U_o - U_i}{R_2}$
  - 流过 $R_1$ 的电流：$I_{R1} = \frac{U_- - 0}{R_1} = \frac{U_i}{R_1}$
  - 因为 $I_{R2} = I_{R1}$，即： $\frac{U_o - U_i}{R_2} = \frac{U_i}{R_1}$

- **化简得出电压传输关系**：

  $$U_o = \frac{R_1 + R_2}{R_1} U_i = \left(1 + \frac{R_2}{R_1}\right) U_i$$

### 2. 电路特性

- **闭环电压放大倍数**：$A_{uf} = 1 + \frac{R_2}{R_1}$ *(注：放大倍数* $A_{uf} \ge 1$*，同相放大)*
- **输入电阻**：$R_i = \infty$ *(因为信号直接输入运放同相端，运放自身输入阻抗无穷大，能将输入电压无失真地传输过来)*
- **输出电阻**：$R_o \approx 0$

### 📝 补充例题 1

**题目**：在一个同相比例放大电路中，已知反馈电阻 $R_2 = 40\text{ k}\Omega$，接地电阻 $R_1 = 10\text{ k}\Omega$，输入电压 $U_i = 1.5\text{ V}$。求该电路的放大倍数 $A_{uf}$ 和输出电压 $U_o$。 **求解过程**：

1. 计算放大倍数：$A_{uf} = 1 + \frac{R_2}{R_1} = 1 + \frac{40\text{ k}\Omega}{10\text{ k}\Omega} = 1 + 4 = 5$
2. 计算输出电压：$U_o = A_{uf} \cdot U_i = 5 \cdot 1.5\text{ V} = 7.5\text{ V}$ **答案**：该电路放大倍数为 $5$ 倍，输出电压为 $7.5\text{ V}$。

## 二、 反相比例放大器

反相比例放大器是指输入信号 $U_i$ 经过电阻 $R_1$ 接入运放的反相输入端（-）的放大电路。

### 1. 电路结构与推导

![image-20260605105757984](./%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF-CH2.2-%E8%BF%90%E6%94%BE%E6%9E%84%E6%88%90%E7%9A%84%E6%AF%94%E4%BE%8B%E6%94%BE%E5%A4%A7%E5%99%A8.assets/image-20260605105757984.png)

- **信号输入**：接反相端（-）。
- **同相端接法**：同相端（+）接地。
- **反馈网络**：输出 $U_o$ 经反馈电阻 $R_2$ 接回反相端（-）。

**推导过程（修正笔记中的公式书写）**：

- **虚短**：$U_- = U_+ = 0$（此时反相端称为**虚地**）。

- **虚断**：运放输入端无电流（$I_- = 0$）。因此输入电流 $I_i$ 全部流向反馈电阻 $R_2$，即 $I_i = I_f$。

- **列方程**：

  - 流过 $R_1$ 的电流：$I_i = \frac{U_i - U_-}{R_1} = \frac{U_i - 0}{R_1} = \frac{U_i}{R_1}$
  - 流过 $R_2$ 的电流：$I_f = \frac{U_- - U_o}{R_2} = \frac{0 - U_o}{R_2} = -\frac{U_o}{R_2}$
  - 因为 $I_i = I_f$，即： $\frac{U_i}{R_1} = -\frac{U_o}{R_2}$

- **化简得出电压传输关系**：

  $$U_o = -\frac{R_2}{R_1} U_i$$

  *(负号表示输出与输入是反相关系)*

### 2. 电路特性

- **闭环电压放大倍数**：$A_{uf} = -\frac{R_2}{R_1}$
- **输入电阻**：$R_i = R_1$ （有限值，不再是无穷大）
  - **【解答笔记中的疑问：为什么** $R_i=R_1$**？】** 从输入端看进去，输入电阻等于输入电压除以输入电流（$R_i = \frac{U_i}{I_i}$）。因为反相端是“虚地”（电位为 $0\text{ V}$），所以输入信号源看进去，相当于直接接了一个接地的电阻 $R_1$。因此 $R_i = \frac{U_i}{U_i / R_1} = R_1$。设计电路时为了不影响信号源，通常要求 $R_1$ 不能太小。
- **输出电阻**：$R_o \approx 0$

### 📝 补充例题 2

**题目**：设计一个反相比例放大电路，要求实现 $-10$ 倍的电压放大，且要求电路的输入电阻不小于 $10\text{ k}\Omega$。请确定 $R_1$ 和 $R_2$ 的取值。若输入 $U_i = 0.5\text{ V}$，求 $U_o$。 **求解过程**：

1. 根据反相放大器输入电阻特性，$R_i = R_1$。为了满足条件，我们选取 $R_1 = 10\text{ k}\Omega$。
2. 根据放大倍数公式 $A_{uf} = -\frac{R_2}{R_1} = -10$，可得 $R_2 = 10 \cdot R_1 = 100\text{ k}\Omega$。
3. 计算输出电压：$U_o = A_{uf} \cdot U_i = -10 \cdot 0.5\text{ V} = -5\text{ V}$。 **答案**：选取 $R_1 = 10\text{ k}\Omega$， $R_2 = 100\text{ k}\Omega$。输出电压为 $-5\text{ V}$。

## 三、 两种放大器特性结论对比（重要考点）

| 特性                  | 同相比例放大器                    | 反相比例放大器                            |
| --------------------- | --------------------------------- | ----------------------------------------- |
| **信号输入端**        | 同相端（+）                       | 反相端（-）                               |
| **反馈接入端**        | **均接回反相端（-）以构成负反馈** | **均接回反相端（-）以构成负反馈**         |
| **放大倍数** $A_{uf}$ | $1 + \frac{R_2}{R_1}$             | $-\frac{R_2}{R_1}$                        |
| **放大倍数范围**      | $A_{uf} \ge 1$ (只能放大)         | 绝对值可大于1 (放大)、等于1、小于1 (衰减) |
| **输入电阻** $R_i$    | $\infty$ (极高，不消耗信号源电压) | $R_1$ (有限值)                            |
| **输出电阻** $R_o$    | $\approx 0$ (带负载能力强)        | $\approx 0$ (带负载能力强)                |

## 四、 比例放大器的扩展应用电路

### 1. 电压跟随器 (Voltage Follower)

同相比例放大器的特殊形式。当 $R_1 = \infty$（断开），$R_2 = 0$（短路直接将输出连到反相端）时：

- **传输关系**：$U_o = U_i$ （$A_{uf} = 1$）
- **特性**：输入阻抗极高（$\infty$），输出阻抗极低（$0$）。
- **作用**：主要用于**隔离**和**阻抗变换**。它可以把高阻抗信号源无失真地传输给低阻抗负载。



![image-20260605110825159](./%E6%A8%A1%E6%8B%9F%E7%94%B5%E8%B7%AF-CH2.2-%E8%BF%90%E6%94%BE%E6%9E%84%E6%88%90%E7%9A%84%E6%AF%94%E4%BE%8B%E6%94%BE%E5%A4%A7%E5%99%A8.assets/image-20260605110825159.png)

### 2. 直流平衡电阻 $R_p$

在运放的另一个输入端（同相端或反相端）串联一个接到地（或信号源）的电阻 $R_p$。

- **取值**：$R_p = R_1 // R_2$ （即 $R_1$ 和 $R_2$ 的并联值）。
- **【解答笔记中的疑问：有啥用？】** 实际运算放大器并不是绝对理想的，内部的晶体管需要微小的偏置电流。如果在静态（直流）情况下，运放正负两端看出去的等效电阻不相等，就会因为偏置电流产生额外的输入失调电压，导致输出端存在直流误差。**加上** $R_p$ **可以保证运放两端在直流状态下的阻抗平衡，消除静态偏置电流带来的误差。** （注：加 $R_p$ 不会改变交流状态下的虚短/虚断特性，因此**不影响理论放大倍数**）。

### 3. 输出端串联电阻 $R_3$

在运放的输出端与反馈回路之间串联一个电阻 $R_3$。

- **结论**：只要引出反馈的位置在 $R_3$ 之后，串联 $R_3$ **不影响电路的整体放大倍数**。
- **原因**：运放是一个深度负反馈系统，反馈网络会强制调节运放的输出，使得反馈点的电压严格按照反馈比例等于输入设定值。$R_3$ 上的压降会被运放内部自动提高增益来补偿。
