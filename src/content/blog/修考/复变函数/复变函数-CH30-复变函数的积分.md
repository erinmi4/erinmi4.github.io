# 复变函数的积分 (Integration of Complex Functions)

在复变函数理论中，积分不仅是核心的计算工具，更是连接“微分”（解析性）与“级数展开”（留数理论）的桥梁。本章我们将从复变积分的**基本定义**出发，掌握**两大核心计算方法**，并通过经典例题深入探讨“积分与路径的关系”。

## 一、 复变积分的基本定义

复变函数的积分是定义在**有向、简单光滑（或分段光滑）曲线**上的。

### 1. 核心概念直观理解

为了在计算时少走弯路，我们需要直观理解以下几个关于积分路径 $C$ 的核心概念：

- **有向曲线（Oriented Curve）**：复积分的方向至关重要。设曲线参数方程为 $z = z(t)$（$t \in [\alpha, \beta]$），则起点为 $z(\alpha)$，终点为 $z(\beta)$。若方向相反，积分值将相差一个负号。
    
- **光滑曲线（Smooth Curve）**：直观上就是“没有尖点”的曲线。数学上要求参数方程 $z(t) = x(t) + i y(t)$ 在区间上具有连续导数，且 $z'(t) \neq 0$。
    
- **分段光滑（Piecewise Smooth）**：由有限段光滑曲线首尾相接而成的曲线（如矩形边界、折线等）。
    

## 二、 计算复变函数积分的两大基本方法

设复变函数 $f(z) = u(x,y) + i v(x,y)$ 定义在有向光滑曲线 $C$ 上。如何将其转化为我们熟悉的实函数积分？主要有两种方法：

### 方法 1：化为实第二类平面曲线积分法（代数拆分）

利用复数的代数形式 $z = x + iy \implies dz = dx + i\,dy$，直接带入积分式中展开：

$$\int_{C} f(z)\,dz = \int_{C} (u + iv)(dx + i\,dy)$$

利用复数乘法展开并合并实虚部，即可得到：

$$\int_{C} f(z)\,dz = \int_{C} (u\,dx - v\,dy) + i \int_{C} (v\,dx + u\,dy)$$

> **注意：** 这里的实部和虚部均对应高等数学中的**平面第二类曲线积分**。特别注意实部中是减号（$- v\,dy$）。

### 方法 2：参数代换法（最常用、最强万能法）

若已知曲线 $C$ 的参数方程为 $z = z(t)$（$t \in [\alpha, \beta]$，起点为 $\alpha$，终点为 $\beta$），我们可以直接将 $z$ 替换为参数 $t$：

$$\int_{C} f(z)\,dz = \int_{\alpha}^{\beta} f(z(t)) z'(t)\,dt$$

> **教学小贴士：** 在实际解题中，
> 如果路径是<font color="#2DC26B">圆弧</font>，通常采用极坐标/指数参数 $z = R e^{i\theta}$；
> 如果路径是<font color="#2DC26B">直线段</font>，通常采用直角坐标参数 $z = x + i y$（令 $x=t$ 或 $y=t$）。

## 三、 典型例题解析与补充

为了让大家彻底吃透这两种方法，我们来看以下三个经典例题。

### 【补充例题】演示方法 1（第二类曲线积分法）

**题目**：计算积分 $I = \int_{C} \bar{z}\,dz$，其中 $C$ 是从原点 $0$ 到点 $1+i$ 的直线段。

**解析**：

1. **写出实虚部**：$f(z) = \bar{z} = x - iy \implies u = x, \; v = -y$。
    
2. **带入方法 1 公式**：
    
    $$\int_{C} \bar{z}\,dz = \int_{C} (x\,dx - (-y)\,dy) + i \int_{C} ((-y)\,dx + x\,dy) = \int_{C} (x\,dx + y\,dy) + i \int_{C} (-y\,dx + x\,dy)$$
3. **参数化路径**：从 $0$ 到 $1+i$ 的直线方程为 $y = x$，其中 $x$ 从 $0$ 变到 $1$。此时 $dy = dx$。
    
4. **代入化简计算**：
    
    $$I = \int_{0}^{1} (x\,dx + x\,dx) + i \int_{0}^{1} (-x\,dx + x\,dx) = \int_{0}^{1} 2x\,dx + i \int_{0}^{1} 0\,dx$$

    $$I = \left[ x^2 \right]_0^1 = 1$$

### 【手写例 1】圆弧路径下的参数积分法

**题目**：计算积分 $I = \int_{C} \frac{1}{\sqrt{z}}\,dz$。

> **背景补充说明**：由于被积函数含根号，属于多值函数。在此我们约定取**主值分支**（即取 $-\pi < \arg z \le \pi$，$\sqrt{z} = \sqrt{r}e^{i\frac{\theta}{2}}$，从而 $\frac{1}{\sqrt{z}} = z^{-1/2} = e^{-i\frac{\theta}{2}}$）。

#### ① 情况一：$C_1$ 为自起点 $1$ 到终点 $-1$ 的单位圆**上半圆周**

- **路径参数化**： 在单位圆上，$r = 1$，参数方程为 $z = e^{i\theta}$。 由于起点为 $1$（对应 $\theta = 0$），终点为 $-1$（对应 $\theta = \pi$），故参数范围为 $\theta \in [0, \pi]$。 微元：$dz = i e^{i\theta} d\theta$。
    
- **代入计算**：
    
    $$I_1 = \int_{0}^{\pi} e^{-i\frac{\theta}{2}} \cdot \left( i e^{i\theta} \right) d\theta = i \int_{0}^{\pi} e^{i\frac{\theta}{2}} d\theta$$
    
    根据求导公式 $\left( e^{a\theta} \right)' = a e^{a\theta}$，积分时需要除以系数 $i/2$：
    
    $$I_1 = i \cdot \left[ \frac{e^{i\frac{\theta}{2}}}{\frac{i}{2}} \right]_{0}^{\pi} = 2 \left( e^{i\frac{\pi}{2}} - e^0 \right)$$
    
    因为 $e^{i\frac{\pi}{2}} = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = i$，且 $e^0 = 1$：
    
    $$I_1 = 2(i - 1) = -2 + 2i$$

#### ② 情况二：$C_2$ 为自起点 $1$ 到终点 $-1$ 的单位圆**下半圆周**

- **路径参数化**： 下半圆是从 $1$ 经 $-i$ 到 $-1$。 在主值分支下，辐角范围需落在 $(-\pi, \pi]$。 因此自起点 $1$（对应 $\theta = 0$）到终点 $-1$（对应下极限 $\theta = -\pi$）。 为了计算方便，我们可设 $\theta = -t$（$t \in [0, \pi]$），即 $z = e^{-it}$。 微元：$dz = -i e^{-it} dt$。 被积函数：$z^{-1/2} = (e^{-it})^{-1/2} = e^{i\frac{t}{2}}$。
    
- **代入计算**：
    
    $$I_2 = \int_{0}^{\pi} e^{i\frac{t}{2}} \cdot \left( -i e^{-it} \right) dt = -i \int_{0}^{\pi} e^{-i\frac{t}{2}} dt$$

    $$I_2 = -i \cdot \left[ \frac{e^{-i\frac{t}{2}}}{-\frac{i}{2}} \right]_{0}^{\pi} = 2 \left( e^{-i\frac{\pi}{2}} - e^0 \right)$$
    
    因为 $e^{-i\frac{\pi}{2}} = -i$：
    
    $$I_2 = 2(-i - 1) = -2 - 2i$$

> **关键思考**：为什么起点和终点完全相同的两条路径（$C_1$ 与 $C_2$），积分结果却截然不同？ 这是因为被积函数 $\frac{1}{\sqrt{z}}$ 在原点 $z=0$ 处有奇点（且是多值函数的分支点），积分路径绕过了奇点，所以积分与路径有关。

### 【手写例 2】折线路径下的参数积分与基本性质

在进行本题计算之前，我们需要先明确**复变积分的三大基本性质**。

### 📌 补充：复变积分的基本性质

1. **线性性质**：
    
    $$\int_{C} [a f(z) + b g(z)]\,dz = a \int_{C} f(z)\,dz + b \int_{C} g(z)\,dz$$
2. **方向性**： 设 $C^-$ 是 $C$ 的反向曲线：
    
    $$\int_{C^-} f(z)\,dz = -\int_{C} f(z)\,dz$$
3. **路径可加性（首尾相接）**： 若曲线 $C$ 可以拆分为两段首尾相接的曲线 $C_1$ 和 $C_2$，则：
    
    $$\int_{C} f(z)\,dz = \int_{C_1} f(z)\,dz + \int_{C_2} f(z)\,dz$$

**题目**：计算积分 $I = \int_{C} \operatorname{Re}(z)\,dz$，起点为 $0$，终点为 $1+i$。

#### ① 路径一：$C$ 为直达的直线段（从 $0 \to 1+i$）

- **路径参数化**： 直线方程为 $y = x$，令参数 $x = t, y = t \implies z(t) = t + it = (1+i)t$。 由于起点是 $0$，终点是 $1+i$，因此 $t \in [0, 1]$。 求导：$z'(t) = 1 + i$。 被积函数实部：$\operatorname{Re}(z) = \operatorname{Re}((1+i)t) = t$。
    
- **代入计算**：
    
    $$I_{\text{直}} = \int_{0}^{1} t \cdot (1+i)\,dt = (1+i) \int_{0}^{1} t\,dt$$

    $$I_{\text{直}} = (1+i) \left[ \frac{1}{2}t^2 \right]_{0}^{1} = \frac{1+i}{2} = \frac{1}{2} + \frac{1}{2}i$$

#### ② 路径二：$C$ 为折线（从 $0 \to 1 \to 1+i$）

根据路径可加性，我们可以把折线拆分为水平段 $C_1$ 和垂直段 $C_2$：

##### 1. 水平段 $C_1$（从 $0 \to 1$）

- **参数化**：$y = 0, x = t \implies z(t) = t$，其中 $t \in [0, 1]$。
    
- **求导与实部**：$z'(t) = 1$，$\operatorname{Re}(z) = t$。
    
- **计算**：
    
    $$\int_{C_1} \operatorname{Re}(z)\,dz = \int_{0}^{1} t \cdot 1\,dt = \frac{1}{2}$$

##### 2. 垂直段 $C_2$（从 $1 \to 1+i$）

- **参数化**：$x = 1, y = t \implies z(t) = 1 + it$，其中 $t \in [0, 1]$。
    
- **求导与实部**：$z'(t) = i$，$\operatorname{Re}(z) = 1$。
    
- **计算**：
    
    $$\int_{C_2} \operatorname{Re}(z)\,dz = \int_{0}^{1} 1 \cdot i\,dt = i$$

##### 3. 合并总积分：

$$I_{\text{折}} = \int_{C_1} \operatorname{Re}(z)\,dz + \int_{C_2} \operatorname{Re}(z)\,dz = \frac{1}{2} + i$$

## 四、 总结与承上启下（核心启发）

对比【手写例 2】中两条路径的积分结果：

- **沿直线**：$I_{\text{直}} = \frac{1}{2} + \frac{1}{2}i$
    
- **沿折线**：$I_{\text{折}} = \frac{1}{2} + i$
    

### 💡 重要结论

**复变函数的积分，在一般情况下是与<font color="#ff0000">路径有关</font>的！** 哪怕起点和终点完全一致，只要路径不同，积分结果就可能不同。

### 🔍 课后思考与后续预习

既然大部分时候积分与路径有关，那**在什么情况下，复变函数的积分才会与路径无关呢？**

这直接引出了我们下一章的核心定理——**柯西-古萨（Cauchy-Goursat）基本定理**：[复变函数-CH31-柯西古萨定理](复变函数-CH31-柯西古萨定理.md)

> 如果函数 $f(z)$ 在单连通区域 $D$ 内**解析**（即处处可导，不含奇点），那么 $f(z)$ 沿 $D$ 内任意一条闭曲线的积分都等于 $0$。此时，其在该区域内的积分**只与起点和终点有关，而与路径无关**！

这就是为什么 $\operatorname{Re}(z)$ 积分与路径有关（因为实部函数 $\operatorname{Re}(z) = x$ 在整个复平面上都不满足柯西-黎曼方程，是**非解析**的），而未来我们学到解析函数（如 $e^z, z^2$ 等）时，积分就可以直接套用牛顿-莱布尼茨公式而无需考虑具体路径了。
