## 1. 温故知新：柯西-古萨（Cauchy-Goursat）定理

### 1.1 定理内容

设区域 $D$ 是一个**单连通区域**。如果函数 $f(z)$ 在 $D$ 内**解析**，且在 $D$ 的边界——简单闭曲线 $C$（光滑或逐段光滑）上**连续**，则 $f(z)$ 沿 $C$ 的正向积分值为 0：

$$\oint_C f(z) dz = 0$$

> **关键条件解读**：
> 
> 1. **单连通域**：通俗来说就是“无洞”的区域。
>     
> 2. **内部及边界均解析**：闭路 $C$ 及其内部不能含有任何奇点（不解析的点）。
>     
> 3. 快速判断解析性的标准：通常看分母是否为零、是否存在无意义的分式或负指数幂等。若无上述情况且是由初等函数组成，则全平面解析。
>     

### 1.2 经典例题解析

#### **例 1**：计算积分 $I_1 = \oint_{|z|=1} \frac{3z+5}{z^2+2z+4} dz$

- **分析**：寻找被积函数的奇点（即分母为零的点）。 令分母 $z^2+2z+4 = 0$，解得：
    
    $$(z+1)^2 = -3 \implies z_{1,2} = -1 \pm \sqrt{3}i$$
- **奇点位置判定**： 积分区域为单位圆 $C: |z| = 1$。 计算奇点到原点的距离（模长）：
    
    $$|z_{1,2}| = \sqrt{(-1)^2 + (\pm \sqrt{3})^2} = \sqrt{1+3} = 2$$
    
    因为 $2 > 1$，所以两个奇点 $z_1, z_2$ 均在积分路径 $C$ 的**外部**。
    
- **结论**：被积函数在整个圆盘 $|z| \le 1$ 上解析。由柯西-古萨定理得：
    
    $$I_1 = 0$$

#### **例 2**：计算积分 $I_2 = \oint_{|z|=2} e^z(z^2+1) dz$

- **分析**：被积函数 $f(z) = e^z(z^2+1)$ 是由指数函数和多项式函数构成的乘积。
    
- **奇点位置判定**：该函数在整个复平面 $\mathbb{C}$ 上都无任何不解析的点（即在全平面解析）。
    
- **结论**：显然在 $|z| \le 2$ 上解析，由柯西-古萨定理得：
    
    $$I_2 = 0$$

#### **例 3**：计算积分 $I_3 = \oint_{|z|=1} \frac{e^z}{\cos z} dz$

- **分析**：寻找分母为零的点，即 $\cos z = 0$。 解得奇点为：
    
    $$z_k = \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$$
- **奇点位置判定**： 离原点最近的奇点为 $z_0 = \frac{\pi}{2} \approx 1.57$。 因为 $1.57 > 1$，所有的奇点均在单位圆 $|z|=1$ 之外。
    
- **结论**：被积函数在闭区域 $|z| \le 1$ 上解析，由柯西-古萨定理得：
    
    $$I_3 = 0$$

#### **例 4**：计算积分 $I_4 = \oint_{|z|=\frac{1}{2}} \frac{dz}{(z^2-1)(z^3-1)}$

- **分析**：寻找奇点。 令分母 $(z^2-1)(z^3-1) = 0$：
    
    1. 由 $z^2-1=0 \implies z = \pm 1$。
        
    2. 由 $z^3-1=0 \implies z = 1, -\frac{1}{2} \pm \frac{\sqrt{3}}{2}i$。
        
- **奇点位置判定**： 积分区域为半径为 $\frac{1}{2}$ 的圆。
    
    - 奇点 $z = \pm 1$ 的模长均为 $1 > \frac{1}{2}$。
        
    - 奇点 $z = -\frac{1}{2} \pm \frac{\sqrt{3}}{2}i$ 的模长为 $\sqrt{\frac{1}{4} + \frac{3}{4}} = 1 > \frac{1}{2}$。 因此，所有的奇点都在 $|z|=\frac{1}{2}$ 的外部。
        
- **结论**：被积函数在积分闭路内解析，由柯西-古萨定理得：
    
    $$I_4 = 0$$

## 2. 承前启后：为什么需要复合闭路定理？

如果我们把 **例 1** 中的积分区域由 $|z|=1$ 扩大到 $|z|=4$：

$$\oint_{|z|=4} \frac{3z+5}{z^2+2z+4} dz$$

此时，两个奇点 $z_{1,2} = -1 \pm \sqrt{3}i$（模长为 $2$）就**落在了积分区域的内部**。

由于积分区域内含有了“坏点”（非解析点），被积函数在 $|z| \le 4$ 内不再处处解析，**柯西-古萨定理失效，积分值不再等于 0**。

为了解决这种“区域内有洞/奇点”的积分计算问题，我们需要将单连通域的定理推广到多连通域，这就是**复合闭路定理**的由来。它的基本思想是：**通过“扣洞”把不解析的奇点隔离出去，只在解析的区域内进行积分转换。**

## 3. 核心定理：复合闭路定理

### 3.1 定理表述

设有一条简单闭曲线 $C$（外回路），以及 $C$ 内部的若干条互不相交且不包含的简单闭曲线 $C_1, C_2, \dots, C_n$（内回路）。 如果函数 $f(z)$ 在由 $C$ 与所有 $C_k$ 所围成的多连通区域内**解析**，且在各边界曲线上**连续**，则：

$$\oint_C f(z) dz = \sum_{k=1}^n \oint_{C_k} f(z) dz$$

*(注意：此处所有的闭回路 $C$ 和 $C_k$ 均取逆时针（正向）*_旋转)_

```
       C (逆时针)
    .-----------------.
   /   .---.     .---. \
  /   /     \   /     \ \
 |   |  C_1  | |  C_2  | |  <-- 被隔离的奇点在 C_1, C_2 内部
  \   \     /   \     / /
   \   '---'     '---' /
    '-----------------'
```

### 3.2 证明思想（剪线法/加反方向抵消）

定义一条复合闭路 $\Gamma$：

$$\Gamma = C + C_1^- + C_2^- + \dots + C_n^-$$

其中 $C_k^-$ 代表顺时针方向。为了连接内外边界，我们在区域内引入辅助切线（剪线）。

由于我们在切线上往返积分两次，方向相反，积分值恰好抵消。而在包含切线后的新闭合边界内，函数 $f(z)$ 是完全解析的（不包含任何奇点）。 由柯西-古萨定理有：

$$\oint_{\Gamma} f(z) dz = 0 \implies \oint_C f(z) dz + \sum_{k=1}^n \oint_{C_k^-} f(z) dz = 0$$

因为 $\oint_{C_k^-} f(z) dz = - \oint_{C_k} f(z) dz$（顺时针改逆时针需变号），移项即得：

$$\oint_C f(z) dz = \sum_{k=1}^n \oint_{C_k} f(z) dz$$

## 4. 基石积分：$\oint_C \frac{dz}{(z-z_0)^n}$ 的计算与结论（极重要）

复合闭路定理最经典、最重要的应用就是计算下述基石积分。该结论是后续学习**柯西积分公式**与**留数定理**的根基。

### 4.1 问题

设 $C$ 是围绕 $z_0$ 的任意一条顺时针方向的简单正向闭曲线，计算：

$$I = \oint_C \frac{dz}{(z-z_0)^n} \quad (n \in \mathbb{Z})$$

### 4.2 详细推导步骤

1. **应用复合闭路定理**： 由于被积函数仅在 $z = z_0$ 处不解析，我们可以在 $C$ 内部作一个以 $z_0$ 为圆心，$\rho$ 为半径的微小正向圆周 $K$。 根据复合闭路定理，积分路径可以由 $C$ 转换为 $K$：
    
    $$I = \oint_K \frac{dz}{(z-z_0)^n}$$
2. **引入参数方程表示圆周** $K$： 设圆周 $K$ 的参数方程为：
    
    $$z = z_0 + \rho e^{i\theta} \quad (\theta \in [0, 2\pi])$$
    
    对其求导求微分 $dz$：
    
    $$dz = \left(z_0 + \rho e^{i\theta}\right)' d\theta = i \rho e^{i\theta} d\theta$$
3. **代入积分式计算**：
    
    $$I = \int_{0}^{2\pi} \frac{i \rho e^{i\theta} d\theta}{(\rho e^{i\theta})^n} = i \rho^{1-n} \int_{0}^{2\pi} e^{i(1-n)\theta} d\theta$$
4. **分情况讨论解积分**：
    
    - **情况一：当** $n = 1$ **时**
        
        $$I = i \rho^{0} \int_{0}^{2\pi} e^{0} d\theta = i \int_{0}^{2\pi} d\theta = 2\pi i$$
    - **情况二：当** $n \neq 1$ **时**（此处 $n$ 为整数）
        
        $$I = i \rho^{1-n} \left[ \frac{e^{i(1-n)\theta}}{i(1-n)} \right]_{0}^{2\pi} = \frac{\rho^{1-n}}{1-n} \left( e^{i 2\pi (1-n)} - 1 \right)$$
        
        由于 $1-n$ 为非零整数，根据欧拉公式 $e^{i 2\pi k} = 1$（$k \in \mathbb{Z}$），有：
        
        $$e^{i 2\pi (1-n)} - 1 = 1 - 1 = 0 \implies I = 0$$

### 4.3 终极结论

$$\oint_C \frac{dz}{(z-z_0)^n} = \begin{cases} 2\pi i, & n = 1 \\ 0, & n \neq 1 \quad (n \in \mathbb{Z}) \end{cases}$$

> **重要启示**：此积分结果与小圆半径 $\rho$ 毫无关系！它说明：
> 
> - 只有当指数分母为 $1$ 次方时，其环路积分才不为零，结果恒为 $2\pi i$。
>     
> - 其他任何整数阶幂次积分结果均为 $0$。
>     

## 5. 方法应用：经典例题与技巧解析

### **例题 1**：计算积分 $\oint_{|z|=1} \bar{z} dz$（利用共轭转化）

- **分析**：共轭函数 $f(z) = \bar{z}$ 在复平面上处处不解析，直接用柯西定理无从下手。但此题积分路径是单位圆 $C: |z|=1$。
    
- **转化技巧**： 在单位圆 $C$ 上，有：
    
    $$|z| = 1 \implies |z|^2 = z \cdot \bar{z} = 1 \implies \bar{z} = \frac{1}{z}$$
- **计算**： 将 $\bar{z}$ 替换为 $\frac{1}{z}$：
    
    $$\oint_{|z|=1} \bar{z} dz = \oint_{|z|=1} \frac{1}{z} dz$$
    
    由基石积分结论（此处 $z_0 = 0, n = 1$），直接可得：
    
    $$\oint_{|z|=1} \bar{z} dz = 2\pi i$$

#### **知识拓展：若积分路径改为** $|z|=R$

若圆周半径为 $R$，则 $z \cdot \bar{z} = R^2 \implies \bar{z} = \frac{R^2}{z}$。 此时积分值为：

$$\oint_{|z|=R} \bar{z} dz = \oint_{|z|=R} \frac{R^2}{z} dz = R^2 \oint_{|z|=R} \frac{1}{z} dz = R^2 (2\pi i) = 2\pi R^2 i$$

### **例题 2**：计算积分 $\oint_{|z|=2} \frac{dz}{z^2-z}$（部分分式展开 + 复合闭路）

- **分析**： 被积函数 $f(z) = \frac{1}{z^2-z} = \frac{1}{z(z-1)}$，奇点为 $z=0$ 和 $z=1$。 积分闭路 $C: |z|=2$ 包含了这两个奇点。
    
- **解法一：部分分式法（推荐，最直观）** 我们将被积函数裂项分解：
    
    $$\frac{1}{z(z-1)} = \frac{1}{z-1} - \frac{1}{z}$$
    
    代入原积分中，利用积分的线性性质展开：
    
    $$\oint_{|z|=2} \frac{dz}{z^2-z} = \oint_{|z|=2} \frac{dz}{z-1} - \oint_{|z|=2} \frac{dz}{z}$$
    
    对于 $\oint_{|z|=2} \frac{dz}{z-1}$，奇点 $z_0=1$ 在 $|z|=2$ 内部，指数 $n=1$，积分值等于 $2\pi i$。 对于 $\oint_{|z|=2} \frac{dz}{z}$，奇点 $z_0=0$ 在 $|z|=2$ 内部，指数 $n=1$，积分值等于 $2\pi i$。
    
    由此得到：
    
    $$\oint_{|z|=2} \frac{dz}{z^2-z} = 2\pi i - 2\pi i = 0$$
- **解法二：直接用复合闭路定理隔离奇点** 在 $|z|=2$ 内部，以 $z=0$ 和 $z=1$ 为圆心分别作互不重叠的正向微小圆周 $C_1$ 和 $C_2$。 根据复合闭路定理：
    
    $$\oint_{|z|=2} \frac{dz}{z(z-1)} = \oint_{C_1} \frac{dz}{z(z-1)} + \oint_{C_2} \frac{dz}{z(z-1)}$$
    - 在 $C_1$ 内部，$z-1$ 绝不为零，故 $\frac{1}{z-1}$ 解析；
        
    - 在 $C_2$ 内部，$z$ 绝不为零，故 $\frac{1}{z}$ 解析。 通过留数或后续柯西公式同样能算出两个环路积分分别为 $-2\pi i$ 与 $2\pi i$，相加依然得 $0$。
        

### **【新赠巩固例题】例题 3**：计算积分 $\oint_{|z|=2} \frac{2z+1}{z^2-z} dz$

- **目的**：深化对裂项法和基石积分的联合应用，避免误以为所有“多奇点积分”结果都必定为 0。
    
- **解题步骤**：
    
    1. **奇点分析**：奇点仍为 $z=0$ 和 $z=1$，均在积分圆周 $|z|=2$ 内部。
        
    2. **部分分式待定系数分解**： 设 $\frac{2z+1}{z(z-1)} = \frac{A}{z} + \frac{B}{z-1}$。 通分通式：$2z+1 = A(z-1) + Bz$。
        
        - 令 $z = 0 \implies 1 = -A \implies A = -1$。
            
        - 令 $z = 1 \implies 3 = B \implies B = 3$。 所以：
            
            $$\frac{2z+1}{z^2-z} = \frac{3}{z-1} - \frac{1}{z}$$
    3. **带入积分计算**：
        
        $$\oint_{|z|=2} \frac{2z+1}{z^2-z} dz = 3 \oint_{|z|=2} \frac{dz}{z-1} - \oint_{|z|=2} \frac{dz}{z}$$
        
        根据基石积分结论：
        
        $$\oint_{|z|=2} \frac{dz}{z-1} = 2\pi i, \quad \oint_{|z|=2} \frac{dz}{z} = 2\pi i$$
        
        最终积分值：
        
        $$I = 3(2\pi i) - 1(2\pi i) = 4\pi i$$

## 6. 复习核心要点总结（卡片式速记）

1. **单连通（无洞）+ 区域内处处解析** $\implies$ 积分恒为 $0$。（柯西-古萨定理）
    
2. **多连通（有洞）** $\implies$ 大回路积分 $=$ 所有小回路（包裹奇点）积分之和。（复合闭路定理）
    
3. **一阶核心积分公式** $\implies \oint \frac{dz}{z-z_0} = 2\pi i$。
    
4. **高阶/其余积分公式** $\implies \oint \frac{dz}{(z-z_0)^n} = 0 \quad (n \neq 1)$。
    
5. **常用战术**：遇到分母可因式分解的多项式，**优先使用部分分式展开（裂项法）**，将其化为基础的 $\frac{1}{z-z_0}$ 形式，再利用核心公式秒杀积分！
